# 디자인 시스템 규칙

**코드가 정본이다.** 아래 값은 완성된 두 화면(활동 현황 `app/activity/page.tsx`,
고객사 현황 `components/home/*`)에서 실제 추출한 것이다. 새 값을 만들지 말고
이 표에 있는 값만 재사용한다. 표에 없는 값이 필요하면 물어봐라.

톤: 정보 밀도 높은 절제된 스타일. 흰 배경 + `#234ea2` 단일 액센트. 다크모드·보라 없음.

## 여백 / 간격

| 대상 | 값 | 사용처 |
|---|---|---|
| 카드 padding | `14px 16px` | 카드·필터카드·모달헤더·정보창 |
| 페이지 padding | 좌우 대칭(홈 20 / activity `24px 28px`) | 컨테이너 |
| 요소 간 gap | `12` | 검색↔목록↔지도(page/Sidebar), 카드 그리드 |
| 필터/헤더 내부 gap | `8` | activity 필터 바 |

| 장비 목록 gap | `3` | 세로 |

## 카드 구조

- 테두리 `1px #ebebeb`, 배경 `#ffffff`, radius `8`, padding `14px 16px`.
- **hover**: 배경 변경 없음. `transform: translateY(-2px)` + 테두리 `#c7d7f8`.
  `transition: transform 0.15s ease, border-color 0.15s ease`
  (CustomerCard, activity 카드 — 동일).

## 배지 · 칩

- **dot + 텍스트** (상태·서비스 유형): 색을 죽이는 기본 방식. 7~9px 원형 dot만
  색을 갖고 텍스트는 중립(`#6b7280`/`#111827`). 카드·정보창·상세행에 사용.
- **pill 배지** (`99`, 배경 `#f3f4f6`): 카운트/분류 라벨 전용(팀·총 N건).
  틴트 배경(`${color}1a`)은 쓰지 않는다.
- **칩(텍스트)**: 장비명은 배경·테두리 없이 `#234ea2` 텍스트만.

## 필터 패러다임

- **단일 선택 = SegmentedControl** (activity): 트랙 `#f3f4f6`/radius 8/padding 3,
  흰 인디케이터가 슬라이드(radius 6, `transition: left/width 0.25s cubic-bezier(0.4,0,0.2,1)`).
  버튼 12/700, 활성 `#111827` / 비활성 `#6b7280`.
- **다중 선택 = pill 토글** (MapView 지도 필터): radius 6, 12/700, `blur(4px)` 유지.
  - 활성: bg `rgba(255,255,255,0.95)`, 테두리 `#d1d5db`, `#111827`.
  - 비활성: bg `rgba(255,255,255,0.65)`, 테두리 `rgba(235,235,235,0.8)`, `#9ca3af`.

## 그림자 정책

- **모달·팝업·드롭다운에만 허용.** 그 외(카드·버튼·입력·필터·리스트)는 전부 제거,
  `border 1px`로 구분한다.
- 허용 예: 모달 `0 20px 60px rgba(0,0,0,0.22)`, 정보창 `0 16px 40px rgba(0,0,0,0.18)`,
  모달 내부 스크롤 힌트 inset shadow.
- 그라데이션 전면 금지. 스크롤 힌트는 inset shadow(모달 내) 또는 셰브론 pill(그 외).

## 목록 행 구조

- 행: `display:flex`, `padding: 11px 12px`, `gap: 12`, `border-bottom: 1px #ebebeb`.
- 좌: 제목 15/600/`#111827`(lh 22) + 설명 12/400/`#9ca3af`(lh 16, mt 3), 둘 다 ellipsis.
- 우(고정폭): 유형 13/500 + dot 9px / 메타 12(유무상 `#6b7280` · ` · ` `#d1d5db` · 날짜 `#9ca3af`).
- 스크롤바는 숨기고(`scrollbar-width:none`) 넘침을 시각 힌트로 알린다.

## 금지 사항

- 표에 없는 hex·size·radius 신규 생성 금지.
- 그라데이션 금지. 모달/팝업 외 box-shadow 금지.
- 이모지를 UI 아이콘으로 쓰지 않는다 — lucide식 SVG만.
- 배지에 상태색 틴트 배경 쓰지 말 것 — 색은 dot으로만.
- 로직(쿼리·상태·props)은 스타일 작업 중 건드리지 않는다.

## 예외

- `borderRadius: '50%'`(dot·닫기 버튼·아바타)는 원형 유지 — pill로 바꾸지 말 것.
- react-pdf 인쇄용 색(`#000` 등)은 화면 토큰으로 치환 금지.
