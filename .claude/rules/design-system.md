고객사 현황 `components/home/*`)에서 실제 추출한 것이다. 새 값을 만들지 말고

## Radius

**정본은 `lib/radius.ts` 의 `R` 이다.** 숫자를 직접 적지 않는다
(`scripts/radius-check.js` 가 막는다). CSS 쪽 짝은 `app/globals.css` 의 `--radius-*`.

| 토큰 | 값 | 사용처 |
|---|---|---|
| `R.tag` | `4` | 태그(분류·상태 꼬리표) |
| `R.icon` | `6` | 아이콘 버튼 |
| `R.control` | `8` | 버튼·입력칸·셀렉트·드롭다운 |
| `R.tile` | `10` | 통계 타일 |
| `R.card` | `12` | 카드·패널 |
| `R.modal` | `14` | 모달 |
| `R.pill` | `999` | 칩(필터)·숫자 배지 |
| `'50%'` | — | dot, 닫기 버튼, 아바타 (토큰 밖 예외) |

2026-11-20 전수 치환(1,050건/147파일) 전에는 카드 8·버튼 6 이었다. 역할별로
갈라 두었으니, 값이 같아도(`control` 8 과 옛 카드 8) 역할 이름을 골라 쓴다.

## 카드 구조

- 테두리 `1px #ebebeb`, 배경 `#ffffff`, radius `R.card`, padding `14px 16px`.
- **hover**: 배경 변경 없음. `transform: translateY(-2px)` + 테두리 `#c7d7f8`.
  `transition: transform 0.15s ease, border-color 0.15s ease`
  (CustomerCard, activity 카드 — 동일).

## 배지 · 칩

- **dot + 텍스트** (상태·서비스 유형): 색을 죽이는 기본 방식. 7~9px 원형 dot만
  색을 갖고 텍스트는 중립(`#4b5563`/`#111827`). 카드·정보창·상세행에 사용.
- **pill 배지** (`R.pill`, 배경 `#f3f4f6`): 카운트/분류 라벨 전용(팀·총 N건).
  틴트 배경(`${color}1a`)은 쓰지 않는다.
- **칩(텍스트)**: 장비명은 배경·테두리 없이 `#234ea2` 텍스트만.

## 필터 패러다임

- **고르지 않은 필터 글자는 `#6b7280`** (SegmentedControl·pill 공통). 2026-11-23 전에는 `#9ca3af` 였는데,
  읽고 나서 고르는 글자라 대비 4.5:1 을 넘겨야 한다. `#9ca3af` 는 **쓸 수 없는 항목(disabled)** 에만 남는다.
- **단일 선택 = SegmentedControl** (activity): 트랙 `#f3f4f6`/radius `R.control`/padding 3,
  흰 인디케이터가 슬라이드(radius `R.icon`, `transition: left/width 0.25s cubic-bezier(0.4,0,0.2,1)`).
  버튼 12/700, 활성 `#111827` / 고르지 않음 `#6b7280` / 쓸 수 없음 `#9ca3af`.
- **다중 선택 = pill 토글** (MapView 지도 필터): radius `R.icon`, 12/700, `blur(4px)` 유지.
  - 활성: bg `rgba(255,255,255,0.95)`, 테두리 `#d1d5db`, `#111827`.
  - 고르지 않음: bg `rgba(255,255,255,0.65)`, 테두리 `rgba(235,235,235,0.8)`, `#6b7280`.

## 메모를 보여 주는 두 모양

- **목록 한 줄의 메모 = 아이콘 + 팝오버**(`MemoPopover`). 없어도 자리를 남긴다 —
  행마다 열이 어긋나지 않는 것이 먼저다.
- **읽는 자리의 메모 = 글자 + 호버**(`MemoHoverText`, 2026-11-20). 라벨 옆에 한 줄로
  줄여 두고 호버 **300ms** 뒤에 뜬다. 떠오르는 판의 생김새는 두 모양이 같은 것을 쓴다
  (`MEMO_PANEL_STYLE`). 폰(≤640)에서는 뜨지 않고 줄바꿈으로 전부 보여 준다.

## 그림자 정책

- **모달·팝업·드롭다운에만 허용.** 그 외(카드·버튼·입력·필터·리스트)는 전부 제거,
  `border 1px`로 구분한다.
- 허용 예: 모달 `0 20px 60px rgba(0,0,0,0.22)`, 정보창 `0 16px 40px rgba(0,0,0,0.18)`,
  모달 내부 스크롤 힌트 inset shadow.
- 그라데이션 전면 금지. 스크롤 힌트는 inset shadow(모달 내) 또는 셰브론 pill(그 외).

## 목록 행 구조

- 행: `display:flex`, `padding: 11px 12px`, `gap: 12`, `border-bottom: 1px #ebebeb`.
- 좌: 제목 15/600/`#111827`(lh 22) + 설명 12/400/`#9ca3af`(lh 16, mt 3), 둘 다 ellipsis.
- 우(고정폭): 유형 13/500 + dot 9px / 메타 12(유무상 `#6b7280` · ` · ` `#d1d5db` · 날짜 `#9ca3af`).
- 스크롤바는 숨기고(`scrollbar-width:none`) 넘침을 시각 힌트로 알린다.

## 금지 사항

- 표에 없는 hex·size 신규 생성 금지. radius 는 `lib/radius.ts` 의 `R` 만 쓴다(숫자 직접 금지).
- 그라데이션 금지. 모달/팝업 외 box-shadow 금지.
- 이모지를 UI 아이콘으로 쓰지 않는다.
  lucide 스타일 인라인 SVG를 사용한다 (stroke-width 2, 선 아이콘).
  lucide-react 패키지는 미설치이므로 import 하지 마라.
- 배지에 상태색 틴트 배경 쓰지 말 것 — 색은 dot으로만.
- 로직(쿼리·상태·props)은 스타일 작업 중 건드리지 않는다.

## 예외

- `borderRadius: '50%'`(dot·닫기 버튼·아바타)는 원형 유지 — pill로 바꾸지 말 것.
- react-pdf 인쇄용 색(`#000` 등)은 화면 토큰으로 치환 금지.
- PDF 모달 뷰어 본문 바탕 `#e6e6e6`(`lib/pdfViewer.ts` 의 `VIEWER_BG`)은
  **브라우저 PDF 뷰어의 배경색**과 맞춘 값이다 — 다르면 창과 문서 사이에 띠가 보인다.
  화면 토큰으로 치환 금지(위 react-pdf 색과 같은 성격이다).
- transition 기본은 `0.15s ease`. `0.25s cubic-bezier(0.4,0,0.2,1)`는
  SegmentedControl 슬라이딩 인디케이터 전용 예외.
