# EMS 사용 설명서

아크레텍 코리아 계측사업부 사내 업무 시스템(EMS) 사용 안내서입니다.
그동안 엑셀로 작성하시던 견적서를 EMS에서 작성하는 방법을 중심으로, 고객사·영업기회·수리·재고 관리까지 함께 정리했습니다.

- **대상**: 계측사업부 영업·엔지니어 전 직원
- **읽는 방법**: 처음 쓰시는 분은 1장부터 4장까지 순서대로 읽어보시면 됩니다. 3장(견적서 작성)이 가장 중요합니다.
  현장 서비스 인원은 2장(고객사 관리)을, 영업 담당자는 5장(영업기회 관리)을 함께 보시면 좋습니다.

## 1. 시작하기

### 1-1. 로그인과 첫 화면

회사에서 발급받은 이메일 주소와 비밀번호로 로그인합니다.
로그인하면 아래와 같은 첫 화면(개인 대시보드)이 열립니다.

![](<screenshots/개인 대시보드 전체.png>)

화면은 크게 네 부분입니다.

| 위치 | 이름 | 내용 |
|---|---|---|
| 맨 위 | 인사말 · 오늘 날짜 | `80CS 권재원 선임님, 안녕하세요` 처럼 소속과 이름이 표시됩니다 |
| 왼쪽 위 | 활동 요약 | 이번 달 내 활동이 유형별 건수와 합계로 정리됩니다 |
| 왼쪽 아래 | 알림 | 발주서 등록, 주문 완료 같은 소식이 최신순으로 쌓입니다 |
| 오른쪽 | 내 견적 | 내가 작성한 견적서 목록과 실적 요약입니다 (4장) |

**활동 요약 카드**

- 내 이름과 직급 아래에 **건수가 있는 유형만** 줄줄이 나오고, 맨 아래에 **합계**가 표시됩니다.
- 서비스 방문(신규설치 · 이전설치 · A/S · B/S · 교육 · 유선기술지원)과 영업 활동(전화상담 · 방문미팅 · 사양검토 · 경쟁입찰)이 **함께** 집계됩니다.
- 카드 오른쪽 위 **◀ 2026년 8월 ▶** 로 달을 바꿔 봅니다. 다음 달로는 넘어가지 않습니다.
- **카드를 누르면** 그 달에 다녀온 곳이 한 건씩 나오는 상세 창이 열립니다. 창의 내용은 7-2절과 같습니다.
- 이 카드는 **고객사 화면을 볼 수 있는 팀**에만 나옵니다.

**알림 카드**

- 최근 **다섯 건**만 보여줍니다. 그보다 많으면 아래에 `외 N건 · 상단 알림에서 전체 보기` 라고 안내가 붙습니다.
- 전체 알림은 화면 오른쪽 위 **종 모양 아이콘**에서 봅니다 (1-3절).

**내 견적**

- 화면 높이에 맞춰 **한 페이지에 보이는 줄 수가 늘어납니다.** 화면이 크면 열 줄보다 많이 보이고, 그만큼 페이지 넘김 단위도 같이 늘어납니다.
- 건수가 적으면 아래가 빈 줄로 남습니다. 페이지를 넘길 때 화면이 출렁이지 않게 하기 위한 것입니다.

화면 오른쪽 위에는 종 모양 알림 아이콘과 내 이메일 주소가 보입니다.
이메일 주소를 누르면 계정 메뉴가 열리고, **정보 수정**(1-4절)과 **로그아웃**을 할 수 있습니다.

> **휴대전화로 로그인하면 첫 화면이 고객사 현황(2장)으로 열립니다.**
> 현장에서는 업체와 장비를 먼저 보기 때문입니다. 고객사 화면 권한이 없는 팀은 지금까지처럼 개인 대시보드로 열립니다.

### 1-2. 상단 메뉴와 권한

화면 맨 위에 항상 메뉴가 있습니다. 어느 화면에 있든 이 메뉴로 이동합니다.

![](<screenshots/변경된 탭.png>)

| 메뉴 | 하위 항목 | 누르면 나오는 것 |
|---|---|---|
| **20·80** | 고객사 현황 | 지도와 업체 목록 (2장) |
| | 20 수리등록 | 수리품 입고·진행 관리 (9장) |
| **대시보드** | 20 대시보드 | 수리 통계 (9-6절) |
| | 80 대시보드 | 영업 숫자와 챙길 것 (6장) |
| | 활동 현황 | 사람별 활동 집계 (7장) |
| **견적서** | — | 견적서 작성 화면 (3장) |
| **영업 현황** | — | 영업기회 판 (5장) |
| **영업관리** | 발주관리 | 발주·계산서 처리 (10장) |
| | 재고관리 | 부품 재고 (10-5절) |
| **건의사항** | — | 건의사항 게시판 (8장) |
| **관리자** | 실적 현황 | 회사 전체 실적 (12-8절) |
| | 유지보수 | 직원·팀·목표금액 등 관리 (12장) |

- 메뉴에 마우스를 올리면 하위 항목이 아래로 펼쳐집니다. `견적서`·`영업 현황`·`건의사항` 처럼 하위 항목이 없는 메뉴는 바로 이동합니다.
- 키보드로도 쓸 수 있습니다. 메뉴에서 **Enter** 또는 **↓** 를 누르면 하위 항목이 열리고, **↑ ↓** 로 옮겨 다니며 **Esc** 로 닫습니다.

**메뉴는 권한에 따라 보이는 것만 표시됩니다.**

권한은 **팀 단위**로 정해집니다. 유지보수 → 팀 관리에서 팀마다 아래 여섯 가지를 켜고 끕니다 (12-5절).

| 권한 | 열리는 화면 |
|---|---|
| 고객사 | 고객사 현황 · 업체 상세 · 20 수리등록 |
| 대시보드 | 20 대시보드 · 80 대시보드 · 활동 현황 |
| 견적서 | 견적서 작성 (부품 검색도 이 권한을 봅니다) |
| 영업 현황 | 영업기회 판 |
| 영업관리 | 발주관리 · 재고관리 |
| 관리자 | 실적 현황 · 유지보수 |

- **건의사항**은 로그인한 직원이면 누구나 쓸 수 있습니다.
- 관리자 계정은 팀과 상관없이 모든 화면에 들어갑니다.
- 권한이 없는 화면 주소로 들어가면 `접근 권한이 없습니다` 안내와 함께 **이전으로** 버튼이 나옵니다.
- 필요한 메뉴가 보이지 않으면 관리자에게 말씀해 주세요. 팀 권한이 바뀐 뒤에는 **화면을 새로고침해야** 메뉴에 반영됩니다.

### 1-3. 알림 확인하기

화면 오른쪽 위 **종 모양 아이콘**을 누르면 최근 알림이 열립니다.
읽지 않은 알림이 있으면 아이콘에 숫자가 표시됩니다.

![](<screenshots/최근알림.png>)

알림은 이런 경우에 옵니다.

| 알림 | 받는 사람 |
|---|---|
| 📦 발주서 등록 | 영업관리팀과 관리자 |
| ✅ 주문 완료 | 그 견적서를 작성한 사람 |
| 🧾 세금계산서 발행 요청 | 영업관리팀과 관리자 |
| 🎉 세금계산서 발행 완료 | 그 견적서를 작성한 사람 |
| 📅 출하일정/메모 업데이트 | 그 견적서를 작성한 사람 |
| 출고 요청 / 승인 / 반려 | 재고 담당자 또는 요청자 |

- 알림을 누르면 **관련 화면으로 이동하고 읽음 처리**됩니다.
  다만 그 견적이나 요청이 **자동으로 선택되지는 않습니다.** 목록 화면까지만 이동하므로, 알림에 적힌 견적번호로 그 화면에서 찾으시면 됩니다.
- 목록 위의 **모두 읽음** 을 누르면 전부 읽음으로 바꿀 수 있습니다.
- 알림 목록은 **10초마다 자동으로 새로 불러옵니다.** 화면을 새로고침하지 않아도 됩니다.
- 보관되는 것은 **최근 30건**까지입니다. 그보다 오래된 알림은 목록에서 사라집니다.
- 개인 대시보드의 알림 카드에는 그중 **최근 다섯 건**만 나옵니다 (1-1절).

> **중요**: 내가 직접 처리한 일은 나에게 알림이 오지 않습니다. 자세한 내용은 [11-1절](#11-1-내가-처리한-건은-나에게-알림이-오지-않습니다-)을 확인해 주세요.

### 1-4. 내 계정 (정보 수정 · 비밀번호)

화면 오른쪽 위 이메일 주소를 누르고 **정보 수정** 을 고르면 열립니다.

![](<screenshots/개인 정보 수정.png>)

**프로필**

| 칸 | 설명 |
|---|---|
| 프로필 사진 | 파일을 골라 올립니다. **5MB 이하**만 올라갑니다 |
| 이름 · 이니셜 | 표시되는 이름과 견적번호에 쓰이는 이니셜입니다 |
| 전화번호 | 선택 입력입니다 |
| 이메일 | 로그인 주소라 여기서는 바꿀 수 없습니다 |

넣고 **프로필 저장** 을 누르면 반영됩니다.

**비밀번호 변경**

아래 카드에서 **현재 비밀번호**와 **새 비밀번호**, **새 비밀번호 확인**을 넣고 **비밀번호 변경** 을 누릅니다.

- 새 비밀번호는 **여섯 자 이상**이어야 합니다.
- 현재 비밀번호가 맞지 않으면 `현재 비밀번호가 올바르지 않습니다` 라고 안내가 나옵니다.

## 2. 고객사 관리 (20·80)

상단 메뉴에서 **20·80 → 고객사 현황** 을 누르면 고객사 화면이 열립니다.
업체를 찾고, 담당자와 장비를 등록하고, 방문 기록·영업 기록·영업기회·홀딩을 남기는 곳입니다.
현장에서 가장 자주 쓰는 화면입니다.

### 2-1. 고객사 현황 화면 보기

왼쪽은 업체 목록, 오른쪽은 지도입니다.

![](<screenshots/80 고객사 지도.png>)

- 검색창 오른쪽에 지금 목록에 나온 **업체 수**(예: `1296개`)가 표시됩니다.
- 지도의 **숫자 동그라미**는 그 지역에 있는 업체 수입니다. 누르면 지도가 확대되면서 나뉩니다.
- 지도 왼쪽 위의 **활성 / 잠재 / 이탈** 을 눌러 원하는 상태의 업체만 볼 수 있습니다.
  처음 들어오면 **활성과 잠재만 켜져 있고 이탈은 꺼져 있습니다.** 이탈 업체를 보시려면 눌러서 켜주세요.
- 그 아래 **81 / 83 / 84** 는 장비 종류별로 걸러 보는 버튼입니다. 처음에는 셋 다 켜져 있습니다.
- 오른쪽 위 **+ 업체 등록** 으로 새 업체를 등록합니다 (2-5절).

업체 카드에는 회사명과 상태, 주소, 대리점, 보유 장비가 함께 나옵니다.

- 장비는 **네 개까지** 보이고, 그보다 많으면 `외 N대 더` 로 표시됩니다.
- 주소가 등록되지 않은 업체는 `주소 정보 없음 — 등록 필요` 라고 나옵니다. 지도에도 찍히지 않으니 주소를 넣어주세요.
- **카드를 누르면** 지도가 그 업체 위치로 이동하면서 설명 카드가 열립니다.
- 카드의 **상세보기 >** 를 누르면 그 업체의 상세 화면으로 들어갑니다.

> 상세 화면에 들어갔다가 뒤로 돌아오면 **지도 위치와 목록 스크롤이 보던 그대로 복원**됩니다.
> 업체를 여러 곳 돌아볼 때 처음부터 다시 찾지 않으셔도 됩니다.

휴대전화로 접속하면 화면 위에 **업체 목록 / 지도** 탭이 생깁니다. 좁은 화면에서 목록과 지도를 번갈아 보기 위한 것으로, PC에서는 나오지 않습니다.

### 2-2. 업체 검색하기

목록 맨 위 검색창에 **회사명, 주소, 대리점** 중 아무거나 입력하면 목록과 지도가 함께 걸러집니다.

![](<screenshots/업체 검색.png>)

- 검색창 오른쪽 **✕** 를 누르면 검색어가 지워집니다.
- 조건에 맞는 업체가 없으면 `검색 결과가 없습니다` 와 함께 다른 검색어나 필터를 써보라는 안내가 나옵니다.
  상태·계열 필터가 걸려 있어 안 나오는 경우도 있으니 필터도 함께 확인해 주세요.

### 2-3. 부품 사용 이력 검색

**"이 부품이 어느 업체에 나갔더라"** 를 찾는 기능입니다.
검색창 안 오른쪽의 **업체 / 부품** 을 눌러 **부품** 쪽으로 바꾸면 됩니다.

![](<screenshots/견적 나간 부품 검색 가능.png>)

- 이 토글은 **견적서를 쓸 수 있는 팀에만 보입니다.** 견적 금액이 함께 나오기 때문입니다.
- **부품** 으로 바꾸면 검색창 안내가 `품번, 품명 검색` 으로 바뀝니다.
- **두 글자 이상** 입력해야 찾기 시작합니다.
- 모드를 바꾸면 입력해 둔 검색어는 지워집니다. 화면을 새로 열면 항상 **업체** 로 시작합니다.

결과는 검색창 바로 아래에 **이 부품이 나간 업체** 블록으로 나옵니다.

| 보이는 것 | 설명 |
|---|---|
| 업체명 | 그 견적이 나간 업체입니다. 대리점을 거친 건이면 옆에 **대리점** 표시가 붙습니다 |
| 상태 | 그 견적이 지금 어느 단계인지입니다 (견적중 · 주문완료 · 매출완료 등) |
| 품번 · 품명 | 견적서에 적혔던 그대로입니다. 가격표가 나중에 바뀌어도 **그때 나간 이름 그대로** 찾힙니다 |
| 금액 · 날짜 | 그 품목의 공급가와 견적 날짜입니다 |

- 오른쪽 위 **납품된 것만** 에 체크하면 발주서가 등록된 이후의 건(발주(주문 대기)·주문완료·세금계산서 요청·매출완료)만 남습니다.
  체크를 풀면 **견적만 낸 건까지** 함께 보입니다. 처음에는 풀려 있습니다.
- 줄 오른쪽의 **문서 아이콘**을 누르면 그 견적서 PDF가 열립니다.
- 줄 아무 데나 누르면 그 **업체 상세 화면**으로 이동합니다.
- 블록 제목 왼쪽의 화살표를 누르면 결과를 접었다 펼 수 있습니다.
- 한 번에 최대 50건까지 보여줍니다. 너무 많이 나오면 품번을 더 자세히 입력해 주세요.

### 2-4. 지도에서 길찾기

지도의 마커를 누르면 그 업체의 설명 카드가 열립니다.
카드 아래에는 **상세보기** 와 함께 길찾기 링크가 있습니다.

- **울산 출발 / 구미 출발 / 동탄 출발** — 누르면 그 사무실에서 이 업체까지의 길찾기가 새 창으로 열립니다.
- 주소가 등록되지 않은 업체는 지도에 찍히지 않으므로 길찾기도 쓸 수 없습니다.

### 2-5. 새 업체 등록하기

화면 오른쪽 위 **+ 업체 등록** 을 누릅니다.

![](<screenshots/업체등록.png>)

| 칸 | 설명 |
|---|---|
| **업체명** | 필수입니다 |
| **상태** | 활성 · 잠재 · 이탈 중에서 고릅니다 |
| **주소** | 필수입니다. 전체 주소를 넣으면 지도에 표시할 위치가 자동으로 잡힙니다 |
| **대리점** | 이 업체를 담당하는 대리점입니다 |

그 아래 **장비 정보**와 **담당자 정보**는 **선택 사항**입니다. 비워두고 저장한 뒤 업체 상세에서 나중에 추가하셔도 됩니다.

- 장비는 **장비 라인업 / 모델명 / 옵션 / 시리얼넘버 / 프로그램(ACCTee · Tims · CALYPSO · 없음) / 구분(20 · 81 · 83 · 84)** 을 넣습니다. 카드를 여러 장 추가해 한 번에 여러 대를 등록할 수 있습니다.
- 담당자는 이름 · 직책 · 부서 · 전화번호를 넣습니다.

등록 후에는 목록과 지도에 바로 나타납니다.

> 이미 등록된 업체인지 먼저 검색해 보시고 등록해 주세요. 같은 업체가 두 번 등록되면 견적·활동 이력이 나뉘어 관리가 어려워집니다.

### 2-6. 업체 상세 화면 구성

업체 카드의 **상세보기 >** 를 누르면 그 업체의 상세 화면이 열립니다.
화면은 세로로 세 부분입니다.

![](<screenshots/활동이력탭.png>)

| 위치 | 이름 | 내용 |
|---|---|---|
| 왼쪽 | 업체 정보 · 담당자 | 회사명·주소·대리점과 담당자 목록입니다 (2-7절) |
| 가운데 | 활동 이력 · 장비 | 두 개의 탭으로 나뉩니다 |
| 오른쪽 | 요약 | 견적·장비·최근 방문과 영업기회·홀딩입니다 (2-11절, 2-12절) |

가운데 카드 맨 위의 **활동 이력 / 장비** 를 눌러 화면을 바꿉니다. 장비 옆 숫자는 등록된 장비 수입니다.

- PC에서는 **활동 이력**이 먼저 열립니다.
- 휴대전화에서는 **장비**가 먼저 열립니다. 현장에서는 장비를 먼저 보는 일이 많기 때문입니다.

왼쪽과 오른쪽 열은 화면을 내려도 자리에 남아 있고, 가운데 내용만 흐릅니다.

### 2-7. 업체 정보와 담당자

**업체 정보**

왼쪽 맨 위 카드입니다. 회사명 옆의 색 점이 상태(활성·잠재·이탈)입니다.

- 주소 오른쪽의 **복사 아이콘**을 누르면 주소가 복사됩니다. 복사되면 아이콘이 잠깐 초록색 체크로 바뀝니다.
- 카드 오른쪽 위 **연필 아이콘**을 누르면 **업체 정보 수정** 창이 열립니다. 업체명·주소·대리점·상태를 고칠 수 있습니다.
- 업체 **삭제**는 관리자에게만 보입니다.

**담당자**

그 아래 카드입니다. 제목 옆에 `총 n명` 이 표시됩니다.

![](<screenshots/담당자추가.png>)

- 담당자마다 이름 · 직책 · 부서가 나오고, 전화번호를 누르면 바로 전화가 걸립니다.
- 담당자 줄에 **마우스를 올리면 오른쪽에 연필 아이콘이 나타납니다.** 누르면 **담당자 수정** 창이 열리고, 그 창에서 **삭제**도 할 수 있습니다.
- 카드 아래 **+ 담당자 추가** 로 새 담당자를 넣습니다. 이름만 필수이고 직책·부서·전화번호·이메일은 선택입니다.

> 여기 등록한 담당자는 서비스 레포트를 쓸 때 **고객 확인자**로, 발주서를 등록할 때 **받는 담당자**로 고를 수 있습니다.

### 2-8. 장비와 서비스 레포트

가운데 탭에서 **장비** 를 누르면 장비 카드가 가로로 늘어섭니다.

![](<screenshots/장비탭.png>)

장비 카드에는 다음이 있습니다.

- **사진** — 등록된 사진이 없으면 **사진 등록** 을 눌러 올립니다.
- 카드 오른쪽 위 **연필 아이콘** — 장비 정보를 수정합니다. 그 창에서 장비 **삭제**도 할 수 있습니다.
- **장비명**(라인업 · 모델명 · 옵션), **S/N**, 프로그램, **납입일**
- **패킹리스트** — 파일이 있으면 눌러서 열고, 없으면 **패킹리스트 등록** 으로 올립니다.
- **서비스 레포트 추가** — 방문 결과를 기록합니다.
- 홀딩이 걸려 있으면 장비명 아래에 **홀딩 배지**가 붙습니다 (2-12절).

카드 맨 오른쪽 끝에는 **장비 추가** 자리가 있습니다. 장비가 많아 화면을 넘치면 좌우 이동 버튼으로 넘겨 봅니다.

![](<screenshots/장비추가.png>)

**서비스 기록 카드**

장비 카드 아래에는 그 장비의 서비스 기록이 최신순으로 쌓입니다. 한 건마다 유형(신규설치·A/S 등)과 유상·무상, 내용, 날짜, 방문한 사람이 보입니다.

- 오른쪽 위 **연필 아이콘** — 그 기록을 수정합니다.
- 오른쪽 아래 **레포트 작성** — 아직 레포트를 만들지 않은 건입니다. 누르면 서명 창으로 넘어갑니다.
- 이미 만든 건은 **레포트 열기** 로 바뀝니다.
- 기록 줄에 **마우스를 올리면 유형 옆에 회색 「홀딩」 버튼이 나타납니다.** 이 건으로 홀딩을 걸 때 씁니다 (2-12절).

**서비스 레포트 추가·수정 창**

| 칸 | 설명 |
|---|---|
| **서비스 내용** | 필수입니다. 무엇을 했는지 적습니다 |
| **기타사항** | 레포트 아래쪽에 함께 나갑니다. 선택입니다 |
| **서비스 유형** | 신규 설치 · 이전 설치 · A/S · B/S · 교육 · 유선 기술지원 |
| **고객 담당자** | 필수입니다. 2-7절에서 등록한 담당자 중에서 고릅니다 |
| **방문일자** | 필수입니다 |
| **유무상** | 유상 또는 무상 |
| **시작시간 · 종료시간** | ▲ ▼ 로 30분씩 조절합니다. 아래에 작업시간이 자동으로 계산되어 나오고, 점심시간이 걸치면 그만큼 빼고 계산합니다 |
| **방문 엔지니어** | 필수입니다. 여러 명을 고를 수 있고, 고른 사람은 ✕ 로 뺍니다 |

수정 창에는 **서비스 레포트 파일**이 등록됐는지(등록됨 / 미등록)가 함께 표시되고, 레포트 열기·레포트 삭제·기록 삭제를 할 수 있습니다.

**레포트 만들기 (서명)**

**레포트 작성** 을 누르면 서명 창이 두 단계로 열립니다.

1. **엔지니어 서명** — 칸 안에 서명하고 **다음 →** 를 누릅니다.
2. **고객 담당자 서명** — 고객 담당자분께 서명을 받고 **PDF 생성** 을 누릅니다.

- 잘못 그렸으면 **지우기** 로 다시 그립니다.
- 2단계에서 **← 이전** 로 돌아가 엔지니어 서명을 다시 할 수 있습니다.
- PDF가 만들어지면 그 기록의 버튼이 **레포트 열기** 로 바뀝니다.

### 2-9. 활동 이력 보기

가운데 탭에서 **활동 이력** 을 누르면 그 업체에서 있었던 일이 **한 줄기 시간순**으로 모여 나옵니다.
서비스 방문, 영업 기록, 견적, 홀딩이 한자리에 섞여 최신순으로 쌓입니다.

![](<screenshots/활동이력탭.png>)

**필터**

맨 위 **전체 · 영업 · 서비스 · 견적 · 홀딩** 으로 종류를 골라 볼 수 있고, 이름 옆 숫자가 그 종류의 건수입니다.

**한 건이 보이는 모양**

- 윗줄: 색 점과 **종류**(A/S · 방문미팅 · 견적 · 홀딩 등), 유상·무상, 그리고 그 옆에 **장비 모델명**(서비스), **견적번호**(견적), **연결된 영업기회 제목**(영업 기록), **장비명**(홀딩)이 나옵니다.
- 아랫줄: 내용입니다. 영업 기록이면 내용 뒤 괄호에 **만난 담당자**가, 홀딩이면 경과 일수가 붙습니다.
- 오른쪽: **날짜**와 **담당자**입니다. 방문한 사람이 여러 명이면 쉼표로 이어지고, 길면 줄여서 나옵니다. 마우스를 올리면 전체 이름이 보입니다.
- 내용이 길면 끝에 **펼치기 / 접기** 가 나옵니다.

**누르면 되는 것**

- **견적** 줄을 누르면 그 견적서 PDF가 열립니다 (PDF가 저장된 건만 눌립니다). 대리점을 거친 건에는 **대리점** 표시가 붙습니다.
- **홀딩** 줄을 누르면 홀딩 창이 열립니다. 줄 옆에 **진행 중** 또는 **해제됨** 표시가 붙습니다.
- **영업 기록** 줄에 **마우스를 올리면 오른쪽 위에 연필 아이콘이 나타납니다.** 누르면 그 기록을 수정합니다.
  본인이 쓴 기록에만 나타납니다(관리자는 전부 수정할 수 있습니다).

**날짜 미상**

방문 날짜가 남아 있지 않은 예전 서비스 기록은 목록 맨 아래 **날짜 미상** 으로 접혀 있습니다. 건수를 눌러 펼쳐 보실 수 있습니다.

### 2-10. 영업 활동 기록하기

전화 상담이나 방문 미팅처럼 **장비에 붙지 않는 영업 활동**을 남기는 곳입니다.
활동 이력 탭 오른쪽 위 **+ 영업 기록** 을 누릅니다.

![](<screenshots/영업 방문 기록 추가.png>)

| 칸 | 설명 |
|---|---|
| **활동일** | 필수입니다. 오늘 날짜가 미리 들어가 있습니다 |
| **활동 종류** | 필수입니다. 전화상담 · 방문미팅 · 사양검토 · 경쟁입찰 중에서 고릅니다 |
| **영업기회** | 이 활동이 어느 기회에 대한 것인지 연결합니다. 선택이며, **진행 중인 기회만** 고를 수 있습니다 |
| **만난 담당자** | 그 업체에 등록된 담당자 중에서 고릅니다. 선택입니다 |
| **내용** | 필수입니다. 상담·미팅 내용을 적습니다 |

- 저장하면 활동 이력에 바로 나타나고, **활동 현황**(7장)의 내 건수에도 함께 잡힙니다.
- 수정 창에서는 **삭제**도 할 수 있습니다. 본인이 쓴 기록만 수정·삭제할 수 있습니다.
- 영업기회를 연결해 두면 그 기회 창의 **연결된 활동** 목록에도 함께 모입니다 (2-11절).

### 2-11. 요약과 영업기회

업체 상세 오른쪽 **요약** 카드입니다. 이 업체를 한눈에 보는 곳이자, 영업기회를 만들고 관리하는 곳입니다.

![](<screenshots/영업기회 버튼.png>)

**위쪽 요약**

| 줄 | 내용 |
|---|---|
| 견적 | 이 업체에 나간 견적 건수입니다. **누르면 거래 이력**이 열립니다 (2-13절) |
| (직판 · 대리점) | 대리점을 거친 건이 섞여 있을 때만 그 내역이 아래 줄에 덧붙습니다 |
| 장비 | 등록된 장비 수입니다 |
| 최근 방문 | 가장 최근 서비스 방문 날짜입니다 |

**영업기회**

진행 중인 기회가 건수와 함께 나옵니다. 한 줄에 **단계 · 제목 · 예상 금액**이 들어갑니다.

- 왼쪽의 **단계 표시(회색 알약 모양)를 누르면** 단계를 고르는 작은 메뉴가 열립니다.
  상담 · 사양검토 · 견적제출 · 협상 · 수주 · 실주 중에서 고르면 바로 바뀝니다.
- **실주**를 고르면 사유를 받아야 하므로 영업기회 창이 열립니다.
- 단계는 **그 기회의 담당 영업 본인만** 바꿀 수 있습니다. 다른 사람이 마우스를 올리면 `담당자만 바꿀 수 있습니다` 라고 안내가 뜹니다.
- 제목을 누르면 **영업기회 창**이 열립니다.
- 실주된 기회는 **종료 n건 · 보기** 로 접혀 있습니다.
- 아래 **+ 영업기회** 로 새 기회를 만듭니다.

**영업기회 창**

![](<screenshots/영업기회 등록.png>)

| 칸 | 설명 |
|---|---|
| **업체** | 업체 상세에서 열면 그 업체로 고정됩니다 |
| **제목** | 필수입니다. 예: `A동 라인 증설` |
| **단계** | 상담 · 사양검토 · 견적제출 · 협상 · 수주 · 실주 |
| **담당 영업** | 기본은 본인입니다. 다른 사람으로 바꾸는 것은 관리자만 할 수 있습니다 |
| **예상 금액** | 숫자만 넣습니다. 아래에 `₩150,000,000 · 1.5억` 처럼 확인용으로 표시됩니다 |
| **예상 마감** | **월 단위**로 기록합니다 |
| **실주 사유** | 단계를 실주로 바꿀 때만 나오며 필수입니다. 가격 · 사양·기술 · 납기 · 경쟁사 선정 · 예산 보류·취소 · 사내 결정 지연 · 기타 |
| **보충 메모** | 경쟁사명, 가격 차이 등을 자유롭게 적습니다 |

창 아래쪽에는 **연결된 견적**과 **연결된 활동**이 함께 보입니다.

- 연결된 견적은 견적서를 쓸 때 이 기회를 골라두면 모입니다 (3-2절). 줄을 누르면 견적서 PDF가 열립니다.
- 연결된 활동은 영업 기록에서 이 기회를 골라두면 모입니다 (2-10절).
- **종료** 를 누르면 더 이상 진행하지 않는 기회로 접어둘 수 있고, **종료 해제** 로 되돌립니다.
- **삭제** 도 여기서 합니다. 삭제해도 연결된 활동 기록은 남고 연결만 풀립니다.
- 수정·삭제·종료는 **담당 영업 본인**만 할 수 있습니다(관리자는 전부 가능합니다).

### 2-12. 홀딩 걸고 풀기

**홀딩**은 "현장에서 바로 해결되지 않고 남은 건"입니다.
본사에 부품을 의뢰해 두었거나, 원인을 못 찾아 다시 가야 하는 건처럼 **끝나지 않은 일**을 표시해 두는 기능입니다.

**홀딩 걸기**

1. 가운데 탭에서 **장비** 를 엽니다.
2. 그 장비의 서비스 기록 카드에 **마우스를 올리면 유형 옆에 회색 「홀딩」 버튼이 나타납니다.** 이 버튼을 누릅니다.
3. **홀딩 등록** 창에서 아래를 넣고 저장합니다.

| 칸 | 설명 |
|---|---|
| **제목** | 필수입니다. 예: `본사 부품 의뢰 대기` |
| **시작일** | 기본은 오늘입니다 |
| **최초 메모** | 지금 상황을 적어두면 나중에 경과를 따라가기 쉽습니다. 선택입니다 |

창 아래에는 이 홀딩에 **연결되는 서비스 레포트**가 함께 표시됩니다.

홀딩을 걸면 장비 카드에 **홀딩 · 제목 · 경과일** 배지가 붙고, 그 서비스 기록에는 **홀딩 중** 표시가 붙습니다.
오른쪽 요약 카드의 **홀딩** 줄에도 함께 쌓입니다.

**홀딩 창 보기**

배지나 요약의 홀딩 줄을 누르면 홀딩 창이 열립니다.

![](<screenshots/홀딩 창 상세.png>)

- 맨 위에 장비명과 **진행 중 / 해제됨**, 경과 일수가 표시됩니다.
- **제목**과 **시작일**을 고친 뒤 옆의 **저장** 을 누르면 바뀝니다.
- **경과** 에는 시간순으로 다음이 쌓입니다.

| 종류 | 언제 올라오나 |
|---|---|
| 홀딩 등록 | 홀딩을 걸 때 (최초 메모가 함께 보입니다) |
| 서비스 레포트 | **홀딩 기간에 그 장비를 방문한 기록이 자동으로 올라옵니다.** 따로 연결하지 않으셔도 됩니다. 줄을 누르면 레포트가 열립니다 |
| 메모 | 아래 칸에 적고 **메모 추가** 를 누른 것 |
| 홀딩 해제 | 해제할 때 (해제 사유가 함께 보입니다) |

- 메모 줄에 **마우스를 올리면 연필과 휴지통 아이콘이 나타납니다.** 본인이 쓴 메모만 고치거나 지울 수 있습니다(관리자는 전부 가능합니다).
- 메모 칸에는 `본사 회신, 부품 입고 예정일 등 방문 외 진행 상황` 을 적습니다. **방문 기록은 서비스 레포트가 자동으로 올라오므로** 메모에 다시 적지 않으셔도 됩니다.
- **삭제** 는 홀딩을 등록한 사람과 관리자만 할 수 있습니다. 메모까지 함께 사라지고 되돌릴 수 없습니다.

**홀딩 풀기**

- 홀딩 창의 **홀딩 해제** 또는 홀딩 현황(6-4절)의 **해제** 를 누릅니다.
- **홀딩 해제** 창에서 **해제일**과 **해제 사유**(어떻게 해결됐는지)를 적고 **해제** 를 누릅니다.
- 잘못 해제했으면 홀딩 창에서 **해제 취소** 로 되돌릴 수 있습니다.

> 홀딩이 걸린 장비에 **새 서비스 레포트를 저장하면** `이 장비에 홀딩 중인 건이 있습니다. 해제할까요?` 라고 물어봅니다.
> 해결됐으면 그 자리에서 해제하시고, 아직이면 **나중에** 를 누르면 됩니다.

#### (1) 품목 추가 — 가격표 검색

**본사 제품을 넣을 때 쓰는 기본 방식입니다.**

1. **검색** 칸에 제품 코드나 모델명을 입력합니다.
2. 아래에 뜨는 목록에서 제품을 고릅니다. 정가·구입가와 재고 또는 납기가 함께 표시되니 참고해서 고르시면 됩니다.
3. 고르면 이렇게 자동으로 채워집니다.
   - **검색** 칸에 품번이 표시됩니다 (예: `KT35000`)
   - **품명** 칸에 모델명이 괄호로 들어갑니다 (예: `(DM45505)`)
   - 커서가 품명 칸 맨 앞으로 옮겨지므로, 모델명 앞에 설명을 이어서 적으시면 됩니다 (예: `스타일러스 (DM45505)`)
   - 납기 칸이 비어 있었다면 납기도 자동으로 채워집니다

**판매가는 이렇게 계산됩니다.**

> 구입가(엔화) × 환율 × 관세율 ÷ (1 − 이익률) → 1,000원 단위로 올림

- **수량 / 이익률 / 관세율** 은 행마다 조절할 수 있습니다.
- 이익률은 **40%** 로 시작합니다. `−` `+` 로 5%씩 조절하거나, 숫자를 눌러 직접 입력할 수 있습니다.
- 관세율은 **×1.13** 으로 시작합니다.
- 환율은 수익 분석 영역에 표시된 값을 씁니다. 매일 자동으로 가져오며, 숫자를 두 번 눌러 직접 고칠 수도 있습니다.

품목을 잘못 골랐다면 검색 칸 오른쪽 **✕** 로 선택을 해제하고 다시 검색하시면 됩니다. 다른 제품을 새로 고르면 품명이 새 모델명으로 바뀝니다.

> 이익률 참고 기준은 품목 영역 오른쪽 위 **!** 버튼을 누르면 나옵니다. 대리점·기존 고객사 40%, 신규 고객사 50%, 장비 업그레이드 60% 같은 기준과 정도검사 가격표가 정리되어 있습니다.

| **품명** | 직접 입력합니다 |
| **구입가** | 엔화 기준 구입가입니다 (오른쪽에 `¥` 표시) |
| **판매가** | **이익률 / 판매가** 중 하나를 고릅니다 |

**판매가 방식 두 가지**

- **이익률** — 이익률을 넣으면 판매가가 자동으로 계산됩니다. (가격표 품목과 같은 방식)
- **판매가** — 팔 금액을 직접 넣습니다. 그러면 이익률이 계산되어 표시됩니다.

고객과 금액을 먼저 합의한 경우에는 **판매가**, 마진 기준으로 계산해야 할 때는 **이익률** 을 쓰시면 편합니다.

---

#### (3) 국내조달품 — 우리가 사서 부담하는 것

**PC세트, 측정용 테이블, KOLAS 교정, 항공권처럼 국내에서 구입해 고객에게 제공하는 항목**입니다.

![](<screenshots/국내 조달품.png>)

| 칸 | 입력 내용 |
|---|---|
| **품번** | 직접 입력합니다 (없으면 비워둬도 됩니다) |
| **품명** | 예: `27인치 모니터` |
| **원가** | 우리가 지불한 원화 금액입니다 |
| **수량** | 개수입니다 |

이익률·관세율 칸이 없습니다. **마진을 붙이지 않는 항목**이기 때문입니다.

**이 종류는 다른 셋과 결정적으로 다릅니다. 꼭 알아두세요.**

| 구분 | 어떻게 되나 |
|---|---|
| 고객 견적서(PDF) | 품번·품명·수량은 나오지만 **단가·공급가액·부가세 칸이 `-` 로 표시**됩니다 |
| 고객이 내는 금액 | 합계·부가세·총계에 **포함되지 않습니다** |
| 우리 쪽 원가 | **전액 반영됩니다** |
| 순이익 | 그만큼 **줄어듭니다** |

즉 **고객은 "이 항목이 포함된다"는 사실만 알고 금액은 모릅니다.** 그 비용은 우리가 부담하므로 순이익이 깎입니다.

> **실무 팁**: 국내조달품을 넣으면 이익률이 떨어집니다. 목표 이익률을 맞추려면 **장비 쪽 이익률을 그만큼 올려서** 조정하시면 됩니다. 수익 분석 영역의 **국내 조달품** 줄에 그 금액이 따로 표시되니, 얼마를 만회해야 하는지 바로 확인할 수 있습니다.

---

#### (4) 서비스비 — 설치·교육 비용

**설치·교육처럼 사람이 들어가는 작업 비용**입니다. 견적당 **한 건만** 넣을 수 있습니다(이미 있으면 버튼이 회색으로 바뀝니다).

![](<screenshots/서비스비용추가.png>)

| 칸 | 입력 내용 |
|---|---|
| **품명** | 기본값은 `서비스비` 이고 바꿀 수 있습니다. 견적서에 이 이름 그대로 나갑니다 |
| **금액** | 고객에게 청구할 금액입니다 (공급가) |

그 아래 **부대비용 내역** 이 이 항목의 **원가**가 됩니다.

- **+ 부대비용 추가** 를 누르고 항목을 고릅니다 (인건비(책임)·인건비(선임)·유류대·숙박비 등)
- 항목을 고르면 **단가가 자동으로 채워집니다.** 단가가 정해지지 않은 항목은 직접 입력하시면 됩니다
- **단가 × 인원 × 일수 = 금액** 으로 계산됩니다
- 여러 줄을 넣을 수 있고, 그 합이 **원가 합계** 입니다
- 아래에 **이익**과 **이익률**이 바로 표시됩니다

**부대비용은 고객에게 보이지 않습니다.**
화면에도 빨간 글씨로 `내부 관리용 · PDF에는 표시되지 않습니다` 라고 안내됩니다.
고객 견적서에는 **품명과 금액 한 줄**만 나갑니다. 인건비를 몇 명이 며칠 썼는지는 나가지 않습니다.

> 예: 금액 1,000,000원, 부대비용 인건비(책임) 360,000원 → 원가 360,000원 / 이익 640,000원 / 이익률 64.0%
> 고객 견적서에는 `서비스비 … 1,000,000원` 한 줄만 보입니다.

---

#### 네 가지 한눈에 비교

| | 품목 추가 | 수동입력 | 국내조달품 | 서비스비 |
|---|---|---|---|---|
| 구입가 | 가격표에서 자동 | 엔화 직접 입력 | — | — |
| 원가 | 구입가 × 환율 × 관세 | 구입가 × 환율 × 관세 | 입력한 원가 | 부대비용 합계 |
| 이익률 | 조절 가능 | 조절 가능 | 없음(0%) | 계산 결과 |
| 고객 견적서 금액 | 표시 | 표시 | **`-` 로 표시** | 표시 |
| 개수 제한 | 없음 | 없음 | 없음 | **1건** |

### 3-4. 수익 분석 읽는 법

품목을 넣을 때마다 왼쪽 **수익 분석** 영역이 실시간으로 바뀝니다.

| 줄 | 뜻 |
|---|---|
| 공급가 합계 | 고객에게 청구하는 금액 (국내조달품 제외) |
| 원가 합계 | 우리가 쓰는 비용 (국내조달품 포함) |
| 국내 조달품 | 국내조달품 원가만 따로 (해당 항목이 있을 때만 표시) |
| 매출이익 합계 | 공급가 − 원가, 옆에 이익률(%) |

영역 위쪽에는 오늘 환율과 **이익률 몇 %** 가 표시됩니다. 이익률이 40% 이상이면 초록색, 미만이면 빨간색입니다.
환율 옆 **새로고침 아이콘**을 누르면 환율을 다시 가져옵니다.

품목별로도 구입가·관세×환율·원가·판매단가·공급가·매출이익이 하나씩 정리되어 나옵니다.

### 3-5. 미리보기 확인과 견적 확정

오른쪽 미리보기에서 **품번·품명·수량·단가·공급가액·부가세**가 맞는지 확인합니다.
국내조달품 행은 금액 칸이 `-` 로 보이는 것이 정상입니다.

확인이 끝나면 오른쪽 위 **견적 확정** 을 누릅니다. 확인 창이 뜹니다.

- 공급가 / 원가 / 순이익이 요약되어 보입니다.
- `견적 확정 시 실적으로 기록되며, 관리자의 승인 없이는 삭제가 불가능합니다.` 라는 안내가 있습니다.

**확인**을 누르면 이렇게 됩니다.

1. 견적서가 저장되고 실적에 잡힙니다
2. **PDF 파일이 자동으로 다운로드**됩니다 (파일명: 견적번호_업체명_견적서_품목명)
3. 같은 PDF가 시스템에도 보관되어, 나중에 목록에서 다시 볼 수 있습니다

> 저장 전에는 **업체 선택**과 **품목 금액**이 반드시 있어야 합니다(대리점 건이면 E.U 도 함께). 비어 있으면 빨간 글씨로 알려줍니다.
> 서비스비를 넣었다면 부대비용의 **단가 · 인원 · 일수**도 채워져 있어야 합니다.
> 확정 후에는 견적 번호 뒤 알파벳이 하나 올라가서(A → B) 다음 견적서를 바로 이어서 쓸 수 있습니다.

## 4. 내 견적 관리와 진행 단계

견적서를 확정했다고 끝이 아닙니다. 고객에게서 발주서를 받고, 물건이 나가고,
세금계산서를 발행하기까지의 과정을 **내 견적** 목록에서 이어서 처리합니다.

### 4-1. 내 견적 목록 보기

화면 왼쪽 위 **회사 로고**를 누르면 개인 대시보드가 열립니다. **내 견적** 은 그 화면 오른쪽에 있습니다.

![](<screenshots/나의 견적목록- 발주서 등록 전 상태.png>)

**맨 위 요약 줄**

| 항목 | 뜻 |
|---|---|
| 견적 제출 | 내가 낸 견적서 금액의 합계입니다 |
| 수주 | 발주서를 받아 주문으로 이어진 금액입니다 |
| 매출 완료 | 세금계산서까지 끝나 매출로 잡힌 금액입니다 |
| 순이익 | 매출 완료된 건의 이익 합계입니다 |
| 수주 달성률 / 매출 달성률 | 목표 금액 대비 몇 %인지 보여줍니다 |

**기간 고르기**

왼쪽 위 선택 상자에서 기간을 고릅니다. 처음 들어오면 **유효 견적**으로 되어 있습니다.

- **유효 견적** — 견적 유효기간(작성일 + 1개월)이 아직 지나지 않은 견적만 보여줍니다.
  지금 챙겨야 할 건만 추려 보는 기본 화면입니다.
- 그 외에 월간 · 분기 · 반기 · 연간으로도 볼 수 있습니다.

**검색과 상태 필터**

- 오른쪽 검색칸에 **견적번호 / 고객사 / 내용** 중 아무거나 입력하면 걸러집니다.
- 그 아래 단추들(전체 · 견적중 · 수리중 · 발주(주문 대기) · 주문완료 · 세금계산서 요청 ·
  매출완료 · 삭제 요청 · 실패)로 상태별로 볼 수 있습니다.

**목록에서 보이는 것**

| 칸 | 설명 |
|---|---|
| 견적번호 | 누르면 해당 견적을 볼 수 있고, 옆의 **PDF** 를 누르면 저장된 견적서를 다시 엽니다 |
| 날짜 · 대리점 · 고객사 · 품목 | 견적 요약입니다 |
| 매출액 | 고객에게 청구되는 금액(공급가)입니다 |
| 순이익 | 이익 금액과 이익률입니다. **내부용 숫자이니 화면을 남에게 보이지 않도록 주의해 주세요** |
| 상태 | 지금 어느 단계인지 색깔 배지로 보여줍니다 |
| 관리 | 지금 할 수 있는 처리 단추가 나옵니다 |

**한 페이지에 보이는 줄 수**

목록은 **화면 높이에 맞춰 줄 수가 정해집니다.** 화면이 크면 열 줄보다 많이 보이고, 페이지를 넘기는 단위도 그만큼 커집니다.
건수가 모자라면 아래가 빈 줄로 남습니다. 페이지를 넘길 때 화면이 출렁이지 않게 하기 위한 것입니다.

### 4-2. 견적 상태의 흐름

상태는 아래 순서로 넘어갑니다. 각 단계에서 **누가** 처리하는지가 다릅니다.

```
견적중  ──[내가 발주서 등록]──▶  발주(주문 대기)
                                      │
                        [영업관리 담당자가 주문완료 처리]
                                      ▼
                                  주문완료
                                      │
                          [내가 계산서 요청]
                                      ▼
                             세금계산서 요청
                                      │
                     [영업관리 담당자가 발행 완료 처리]
                                      ▼
                                  매출완료
```

- **견적중** — 견적서를 냈고 아직 발주서를 못 받은 상태입니다.
- **발주(주문 대기)** — 발주서를 등록했고, 본사 주문을 기다리는 상태입니다.
- **주문완료** — 주문이 들어갔고 출하예정일이 잡힌 상태입니다.
- **세금계산서 요청** — 계산서 발행을 요청해 둔 상태입니다.
- **매출완료** — 계산서가 나가고 매출로 확정된 상태입니다.

이 흐름에서 벗어나는 상태도 있습니다.

- **수리중** — 수리 건(20 업무)에서 넘어온 견적입니다.
  국내에서 수리하는 건은 발주 과정 없이 **수리중 → 세금계산서 요청**으로 바로 넘어갑니다.
  그래서 이런 건에는 발주서 등록 단추가 나오지 않습니다.
- **삭제 요청** — 잘못 만든 견적을 지워달라고 요청한 상태입니다. 관리자가 승인해야 실제로 지워집니다.
- **실패** — 수주에 실패한 건입니다. 사유를 함께 적어둡니다.
  손으로 실패 처리한 건과, 유효기간이 지나 **자동으로 실패 처리된 건**(4-6절) 두 가지가 있습니다.

> 견적을 잘못 만들었거나 실패했을 때는 목록 오른쪽 끝 **⋮** 를 누릅니다.
> **삭제 / 실패 처리** 창이 열리면 둘 중 하나를 고르고 사유를 적은 뒤 확정합니다.
> 삭제는 내가 바로 지우는 것이 아니라 **요청**이며, 관리자 승인 후에 처리됩니다.

### 4-3. 발주서 등록하기

고객에게서 발주서를 받으면 이 작업을 합니다. **견적중** 상태의 건에만 단추가 보입니다.

목록 오른쪽 **발주서 등록** 을 누르면 창이 열립니다.

![](<screenshots/발주서등록.png>)

**1) 배송 방법 고르기**

| 방법 | 언제 |
|---|---|
| **직납** | 물건이 고객사로 바로 가거나, 담당자가 직접 가져다 드리는 경우 |
| **택배발송** | 택배로 보내야 하는 경우 |

**택배발송**을 고르면 칸이 더 생깁니다.

![](<screenshots/택배발송 발주서 등록.png>)

- **받는 담당자** — 그 고객사에 등록된 담당자 중에서 고릅니다. 안 골라도 됩니다.
- **배송 주소** — 등록된 **회사 주소**를 그대로 쓰거나, **직접 입력**을 골라 다른 주소를 적습니다.

> 받는 담당자 목록이 비어 있으면 고객사에 담당자가 등록되지 않은 것입니다.
> 2-7절을 참고해 담당자를 먼저 등록해 두시면 편합니다.

**2) 발주서 PDF 올리기**

점선 상자에 **PDF 파일을 끌어다 놓거나**, 상자를 눌러 파일을 고릅니다.
PDF 파일만 올라갑니다. 파일을 올려야 **등록** 단추가 눌립니다.

**3) 등록**

**등록** 을 누르면 상태가 **발주(주문 대기)** 로 바뀌고, 영업관리 담당자에게 알림이 갑니다.

### 4-4. 발주 대기 중일 때

![](<screenshots/발주 대기 상태 사진.png>)

**발주(주문 대기)** 상태에서는 내가 할 일이 없습니다. 영업관리 담당자가 본사에 주문을 넣고
**주문완료 처리**를 하면 다음 단계로 넘어갑니다.

주문완료가 되면 상태 배지 아래에 **출하예정** 날짜가 함께 표시됩니다.
날짜가 아직 안 잡혔으면 `미정` 으로 나옵니다.

![](<screenshots/나의 견적 목록-계산서 요청전 상태.png>)

- 출하예정 옆에 📋 표시가 있으면 담당자가 남긴 메모가 있다는 뜻입니다.
  그 위에 마우스를 올리면 **처리 담당자**와 **메모**가 뜹니다.

### 4-5. 세금계산서 발행 요청

물건이 나가고 계산서를 끊어야 할 때가 되면 요청합니다.
**주문완료** 상태(그리고 국내 수리 건의 **수리중** 상태)에서 **계산서 요청** 단추가 보입니다.

![](<screenshots/계산서 발행 요청.png>)

단추를 누르면 창이 열립니다.

- **요청 발행일** 을 고릅니다. 필수입니다. 날짜를 안 고르면 **발행 요청** 단추가 눌리지 않습니다.
- **발행 요청** 을 누르면 상태가 **세금계산서 요청** 으로 바뀌고 담당자에게 알림이 갑니다.

이후 담당자가 계산서를 발행하면 상태가 **매출완료** 로 바뀌고, 그 금액이 내 **매출 완료** 실적에 반영됩니다.

### 4-6. 견적 유효기간과 자동 실주

견적서에는 **작성일로부터 1개월**의 유효기간이 있습니다. 고객에게 나가는 PDF 에도 그렇게 적혀 나갑니다.

그래서 **견적중 상태로 30일이 지난 견적은 자동으로 실패 처리**됩니다.

- 상태가 **실패** 로 바뀌고, 실패 사유에 `유효기간 만료 (30일)` 이 남습니다.
- 국내에서 수리하는 건(수리중으로 시작하는 건)은 대상이 아닙니다.
- 이 정리는 **관리자가 실적 현황 화면을 열 때** 함께 돌아갑니다. 그래서 만료된 다음 날 바로 바뀌지 않고, 며칠 뒤에 한꺼번에 바뀌어 보일 수 있습니다.

**만료 전에 챙기는 방법**

- 80 대시보드의 **마감 임박 견적** 카드에 남은 날짜가 `D-21` 처럼 표시됩니다 (6-3절).
- 내 견적 목록의 기간 선택을 **유효 견적** 으로 두면 아직 살아 있는 건만 보입니다 (4-1절).

**자동으로 실패된 건은 되돌릴 수 없습니다.**
그 건의 **⋮** 를 눌러보면 아래 안내만 나오고 되돌리기 선택지가 없습니다.

> 유효기간이 만료된 견적입니다. 되돌릴 수 없으며 새 견적서를 작성해주세요

견적일이 이미 한 달을 넘겼기 때문에, 상태만 되살리면 고객에게 나간 PDF 의 유효기간과 어긋나게 됩니다.
아직 살아 있는 건이라면 **새 견적서를 작성**해 주세요.

### 4-7. 실패한 건 되돌리기

**사람이 손으로 실패 처리한 건**은 다시 **견적중** 으로 되돌릴 수 있습니다.

![](<screenshots/견적중으로 되돌리기.png>)

1. 목록 오른쪽 끝 **⋮** 를 누릅니다.
2. **삭제 / 실패 처리** 창에서 **견적중** 을 고릅니다.
3. `견적중으로 되돌립니다. 실패 사유는 지워집니다` 안내를 확인하고 **견적중으로 되돌리기** 를 누릅니다.

- **견적중** 선택지는 지금 상태가 **실패**일 때만 나옵니다.
- 자동으로 실패된 건에는 이 선택지가 나오지 않습니다 (4-6절).
- 되돌리면 실패 사유는 지워지고, 실적 집계에도 다시 진행 중인 건으로 잡힙니다.

### 4-8. 엑셀로 내보내기 ⚠️

견적 내용을 엑셀 파일(`.xlsx`)로 저장할 수 있습니다.

**하는 방법**

1. 목록 왼쪽 끝 **체크박스**로 내보낼 견적을 고릅니다. 맨 위 체크박스를 누르면 전체 선택됩니다.
2. 필터 줄 오른쪽 **엑셀 내보내기 (n)** 단추를 누릅니다. 괄호 안 숫자는 고른 건수입니다.
3. 파일이 바로 내려받아집니다.
   - 1건이면 파일명이 견적번호(예: `KJW20260814-A.xlsx`)입니다.
   - 여러 건이면 `견적_분석표_날짜_n건.xlsx` 로 저장되고, 견적마다 시트가 나뉩니다.

**파일 안에 들어 있는 것**

시트 이름은 **이익률 분석표**입니다. 화면에서 보던 것보다 훨씬 자세합니다.

- 본사 구입가(원가)와 품목별 이익·이익률
- 국내조달품 원가
- 서비스비와 그 부대비용 내역
- 총계(공급가·부가세·원가·이익·이익률)

> ## ⚠️ 반드시 지켜주세요
>
> **이 엑셀 파일에는 원가와 이익률이 그대로 들어 있습니다.**
> 고객에게 나가는 견적서 PDF와는 완전히 다른 문서입니다.
>
> - 고객·대리점·외부 업체에 **절대 보내지 마세요.**
> - 메일에 첨부할 때 파일을 헷갈리지 않도록 주의해 주세요. 고객에게 보낼 것은 **PDF** 입니다.
> - 공용 PC나 공유 폴더에 그대로 두지 마시고, 다 쓰면 지워주세요.
>
> 누가 언제 내려받았는지는 시스템에 기록됩니다.

## 5. 영업기회 관리 (영업 현황)

**영업기회**는 "이 업체에서 이런 건이 될 것 같다" 를 미리 잡아두는 것입니다.
업체 상세에서 기회를 만들고(2-11절), 이 화면에서 **회사 전체의 기회를 한 판에 모아** 단계별로 관리합니다.

상단 메뉴에서 **영업 현황** 을 누르면 열립니다.

### 5-1. 영업 현황 화면 보기

![](<screenshots/영업 기회 현황.png>)

**맨 위 줄**

- **내 기회 / 전체** — 처음에는 **내 기회**로 열립니다. 내가 담당인 기회만 봅니다.
- **업체명 / 제목 검색** — 업체명이나 기회 제목으로 걸러 봅니다.
- 오른쪽 **+ 영업기회** — 새 기회를 만듭니다. 이때는 **업체를 직접 검색해서 고릅니다.**

**판(칸반)**

아래는 단계별 칸입니다. **상담 · 사양검토 · 견적제출 · 협상 · 수주** 다섯 칸이 화면 폭을 나눠 갖습니다.

- 칸 제목 옆 숫자는 그 단계의 **건수**, 그 아래는 **예상 금액 합계**입니다.
- 비어 있는 칸에는 `없음` 이라고 표시됩니다.

**카드에 보이는 것**

| 위치 | 내용 |
|---|---|
| 윗줄 | 업체명 |
| 가운데 | 기회 제목, 예상 금액 |
| 아랫줄 | 담당 영업 · `2026-12 마감 예정` · 연결된 **견적 n건** |
| 맨 아래 | 활동이 한동안 없으면 `n일째 활동 없음` (30일이 넘으면 눈에 띄게 표시됩니다) |

카드를 누르면 **영업기회 창**이 열립니다. 창 안에서 할 수 있는 일은 2-11절과 같습니다.

### 5-2. 단계 옮기기

단계를 바꾸는 방법은 두 가지입니다.

**1) 카드를 끌어다 놓기**

카드를 잡아 다른 칸으로 끌면 그 단계로 바뀝니다. 끌고 가는 동안 놓을 칸에 `여기에 놓기` 가 표시됩니다.
살짝 눌렀다 떼는 것은 카드 열기로 처리되므로, **조금 움직여야** 끌기가 시작됩니다.

**2) 카드의 단계 고르개**

![](<screenshots/종료버튼 보이는 영업기회.png>)

카드에 **마우스를 올리면 오른쪽 위에 단계 고르개가 나타납니다.** 여기서 골라도 단계가 바뀝니다.

- 단계는 **그 기회의 담당 영업 본인만** 바꿀 수 있습니다. 다른 사람에게는 `담당자만 바꿀 수 있습니다` 라고 안내가 뜹니다.
- **실주**를 고르면 사유가 필요하므로 영업기회 창이 열립니다. 사유를 고르고 저장하면 실주로 처리됩니다.
- **수주** 칸의 카드에는 **마우스를 올렸을 때 오른쪽 아래에 「종료」 버튼**이 나타납니다.
  수주까지 갔지만 더 이어갈 것이 없는 건을 여기서 끝냅니다.

### 5-3. 끝난 건 보기

실주했거나 종료한 기회는 판에 남지 않고 **판 아래 「끝난 건」** 으로 접혀 있습니다.

- `끝난 건 n건` 옆에 `실주 n · 종료 n` 이 표시됩니다.
- **펼치기** 를 누르면 카드가 펼쳐지고, 카드를 눌러 내용을 다시 볼 수 있습니다.
- 조건에 맞는 기회가 하나도 없으면 `조건에 맞는 영업기회가 없습니다` 라고 나옵니다.

### 5-4. 영업기회 · 견적 · 활동의 연결

영업기회는 혼자 쓰는 것이 아니라 견적·활동과 이어져 있을 때 쓸모가 있습니다.

| 무엇을 할 때 | 어디서 연결하나 | 결과 |
|---|---|---|
| 영업 활동을 기록할 때 | 업체 상세 **+ 영업 기록** 의 `영업기회` 칸 (2-10절) | 영업기회 창의 **연결된 활동**에 쌓이고, 카드의 `n일째 활동 없음` 이 갱신됩니다 |
| 견적서를 쓸 때 | 견적서 화면 기본 정보의 `영업기회` 칸 (3-2절) | 영업기회 창의 **연결된 견적**에 쌓이고, 카드에 `견적 n건` 으로 표시됩니다 |

> 연결은 **진행 중인 기회**에만 걸 수 있습니다. 이미 실주·종료한 기회는 목록에 나오지 않습니다.
> 영업기회를 지워도 활동 기록과 견적은 그대로 남고, 연결만 풀립니다.

## 6. 80 대시보드와 홀딩 현황

**80 대시보드**는 영업 쪽 숫자와 지금 챙겨야 할 건을 한 화면에 모아 보는 곳입니다.
상단 메뉴에서 **대시보드 → 80 대시보드** 를 누르면 열립니다.

![](<screenshots/80 대시보드.png>)

### 6-1. 이번 달 숫자

맨 위에 다섯 칸이 있습니다. 각 칸 아래에는 **전월 대비** 변화가 함께 나옵니다(`전월 대비 ▲ 4건` / `전월과 같음`).

| 칸 | 무엇을 세나 |
|---|---|
| 이번 달 견적 | 이번 달에 **작성한** 견적 건수입니다 |
| 이번 달 수주 | 이번 달에 **발주서가 등록된** 건수입니다 |
| 이번 달 매출 | 이번 달에 **세금계산서 발행까지 끝난** 금액입니다 |
| 영업 활동 | 이번 달 영업 활동(전화상담 · 방문미팅 · 사양검토 · 경쟁입찰) 건수입니다 |
| C/S 활동 | 이번 달 서비스 방문(신규설치 · A/S · B/S 등) 건수입니다 |

> 회사 전체 기준입니다. 내 실적만 보시려면 로그인 후 첫 화면의 **내 견적**(4장)을 보세요.

### 6-2. 영업기회 카드

왼쪽 큰 카드입니다. 진행 중인 영업기회를 모아 보여줍니다.

- 제목 옆에 전체 건수가, 그 옆에 **정체 n · 마감 임박 n** 이 표시됩니다.
  - **정체** — 마지막 활동(활동이 없으면 등록일)로부터 **30일 이상** 아무 기록이 없는 기회입니다.
  - **마감 임박** — 예상 마감이 **이번 달 안**인 기회입니다(이미 지난 것 포함).
- 그 아래 줄에 단계별 건수(`상담 1 · 사양검토 1 · 견적제출 0 · 협상 1 · 수주 0`)와 오른쪽에 **예상 금액 합계**가 나옵니다.
- 목록에는 업체명 · 기회 제목 · 담당 · 단계 · 예상 금액 · **예상 마감(연월)** 이 한 줄씩 나옵니다. 마감은 빨간색으로 표시됩니다.
- 줄을 누르면 그 기회 창이 열립니다.
- 카드 오른쪽 위 **전체 보기 →** 를 누르면 **영업 현황**(5장)으로 넘어갑니다.

### 6-3. 홀딩 중인 건 · 마감 임박 견적

오른쪽에는 두 개의 카드가 위아래로 있습니다.

**홀딩 중인 건**

![](<screenshots/홀딩 카드.png>)

아직 해제되지 않은 홀딩을 격자로 보여줍니다. 한 칸에 **업체명 · 장비명 · 등록한 사람 · n일째** 가 들어갑니다.

- 칸을 누르면 그 홀딩 창이 열립니다.
- **전체 보기 →** 를 누르면 **홀딩 현황**(6-4절)으로 넘어갑니다.
- 건수가 적으면 빈 칸이 남습니다. 격자 모양을 유지하기 위한 것이라 문제가 아닙니다.

**마감 임박 견적**

견적서의 유효기간(**작성일로부터 1개월**)이 얼마 남지 않은 **견적중** 상태의 건입니다.

- 업체명 · 견적번호 · 만료일과 함께 **D-21** 처럼 남은 날짜가 빨간색으로 표시됩니다.
  당일이면 `오늘 만료`, 이미 지났으면 `만료` 로 나옵니다.
- 남은 날짜가 적은 순으로 정렬되며 최대 일곱 건까지 보여줍니다.
- 해당하는 건이 없으면 `해당 없음` 이라고 나옵니다.

> 여기 올라온 건은 그대로 두면 **자동으로 실패 처리**됩니다. 자세한 내용은 4-6절을 확인해 주세요.

### 6-4. 홀딩 현황 화면

홀딩을 회사 전체 기준으로 모아 보는 화면입니다.
**상단 메뉴에는 없고**, 80 대시보드의 **홀딩 중인 건 → 전체 보기 →** 로 들어갑니다.

![](<screenshots/홀딩현황 페이지.png>)

- 위쪽 **진행 중 / 해제됨 / 전체** 로 골라 보고, 옆 칸에서 **업체 / 장비 / 제목**으로 검색합니다.
- 카드 한 장이 홀딩 한 건입니다.

| 보이는 것 | 설명 |
|---|---|
| 업체명 · 장비명 | 어느 업체의 어느 장비인지 |
| 제목 | 홀딩을 걸 때 적은 제목 |
| 최근 메모 | 가장 마지막에 남긴 메모와 그 날짜 |
| 등록한 사람 · 시작일 · 해제일 | 해제된 건에만 해제일이 붙습니다 |
| n일째 | 시작일로부터 지난 일수입니다. **30일이 넘으면 `30일 초과`** 표시가 함께 붙습니다 |

- 오른쪽 **해제** 를 누르면 홀딩 해제 창이 바로 열립니다(2-12절).
- **상세** 를 누르면 홀딩 창이 열려 경과와 메모를 볼 수 있습니다.
- 새 홀딩은 이 화면에서 만들 수 없습니다. **업체 상세의 장비 카드**에서 겁니다 (2-12절).

## 7. 활동 현황

누가 이번 달에 어디를 다녀왔는지 **사람별로 모아 보는** 화면입니다.
상단 메뉴에서 **대시보드 → 활동 현황** 을 누르면 열립니다.

내 것만 보시려면 로그인 후 첫 화면의 **활동 요약 카드**(1-1절)가 같은 내용을 보여줍니다.

### 7-1. 활동 현황 화면 보기

![](<screenshots/활동기록카드 수정버전.png>)

**맨 위 줄**

- 왼쪽에서 **시작일 ~ 종료일** 을 직접 고르고 **조회** 를 누릅니다.
- 그 옆 **금일 · 작일 · 당월 · 전월** 을 누르면 기간이 한 번에 맞춰집니다. 처음 들어오면 **당월**입니다.
- 오른쪽에서 **팀**을 고릅니다. 처음에는 본인 팀이 골라져 있고, **전체** 로 바꾸면 모든 팀이 나옵니다.

**사람별 카드**

카드 한 장이 한 사람입니다. 이름과 직급, 팀 배지가 위에 있고, 아래에 유형별 건수와 **합계**가 나옵니다.

- **서비스 방문**(신규설치 · 이전설치 · A/S · B/S · 교육 · 유선기술지원)과
  **영업 활동**(전화상담 · 방문미팅 · 사양검토 · 경쟁입찰)이 **함께** 집계됩니다.
- 건수가 있는 유형만 나옵니다. 한 건도 없는 사람은 `활동 기록 없음` 이라고 표시됩니다.
- 여기 잡히는 자료는 업체 상세에서 등록한 **서비스 레포트**(2-8절)와 **영업 기록**(2-10절)입니다.
  목록이 비어 있다면 아직 기록을 남기지 않은 것입니다.

![](<screenshots/활동기록카드(영업들도 이제 기록남음).png>)

> 카드에 나오는 사람은 **고객사와 대시보드를 함께 보는 팀**(현장 팀)입니다.
> 퇴사한 분은 조회 기간 시작일까지 재직했을 때만 나옵니다.

### 7-2. 사람별 상세 보기

카드를 누르면 그 사람의 상세 창이 열립니다.

- 맨 위에 이름 · 직급 · 팀과 조회 기간, **총 n건** 이 표시됩니다.
- 그 아래 **전체 · (유형들)** 로 종류를 골라 봅니다. **건수가 있는 유형만** 단추로 나옵니다.
- 목록에는 한 줄에 **업체명 · 내용 · 유형 · 유상/무상 · 날짜** 가 나옵니다. 영업 활동에는 유상·무상 구분이 없어 그 자리가 비어 있습니다.
- 오른쪽 위 **동선 보기** 로 지도를 엽니다 (7-3절). 방문 기록이 하나도 없으면 눌리지 않습니다.
- 오른쪽 위 **✕** 로 닫습니다.

### 7-3. 동선 지도

상세 창의 **동선 보기** 를 누르면 그 기간에 다녀온 곳이 지도에 순서대로 표시됩니다.

- 같은 날 같은 업체를 여러 번 방문한 기록은 **한 점**으로 묶입니다.
- **유선기술지원**과 **전화상담**은 실제로 간 것이 아니므로 지도에서 빠지고, 아래에 `비방문 n건 제외` 라고 표시됩니다.
- 주소(위치)가 등록되지 않은 업체도 지도에 올릴 수 없어 빠집니다.

지도 오른쪽 아래에 토글이 두 개 있습니다.

| 토글 | 하는 일 |
|---|---|
| **사무실 기준 연결선** | 소속 사무실에서 출발해 돌아오는 것으로 가정하고 선을 그립니다. 실선은 방문지 간 이동, 점선은 사무실 출발·복귀입니다. 위쪽에 `사무실에서 출발·복귀했다고 가정한 경로입니다` 라고 안내가 나옵니다 |
| **주변 업체** | 방문지 반경 5km 안에 있는 다른 고객사를 함께 보여줍니다. 다음 방문 계획을 잡을 때 씁니다 |

- 소속 사무실이 지정되지 않은 분은 사무실 기준 연결선을 쓸 수 없고, `소속 사무실이 지정되지 않았습니다` 라고 나옵니다. 사무실은 유지보수 → 직원 관리에서 지정합니다 (12-4절).
- 왼쪽 아래에는 선의 뜻을 알려주는 범례가 표시됩니다.
- 오른쪽 위 **✕** 로 지도를 닫습니다.

## 8. 건의사항 게시판

시스템을 쓰면서 불편한 점이나 "이렇게 되면 좋겠다" 싶은 것을 남기는 곳입니다.
관리자가 확인한 뒤 답변을 답니다.

상단 메뉴에서 **건의사항** 을 누르면 열립니다.

### 8-1. 글 쓰기

![](<screenshots/건의 사항 등록.png>)

오른쪽 위 **+ 건의사항 작성** 을 누르면 창이 열립니다.

- **분류** — 어느 화면에 대한 건인지 고릅니다. **80 · 20 · 영업관리 · 견적서 · 기타** 중에서 고르며, 처음에는 기타로 되어 있습니다.
- **제목** — 한 줄로 요약해 주세요. (예: `견적서 화면 검색 개선 요청`)
- **내용** — 불편한 점이나 개선 아이디어를 자유롭게 적습니다.

제목과 내용을 채워야 **등록** 이 됩니다. 등록하면 목록 맨 위에 올라갑니다.

> 어느 화면의 어떤 상황이었는지 같이 적어주시면 훨씬 빨리 처리됩니다.
> 예: "견적서 화면에서 가격표 검색할 때, 품번으로는 안 찾아집니다."

### 8-2. 목록 보기와 찾기

목록에는 **제목 · 분류 · 작성자 · 상태 · 답변 · 작성일**이 나옵니다.

- 위쪽 검색칸에 **제목 / 내용 / 작성자** 중 아무거나 넣어 찾을 수 있습니다.
- 그 옆 단추(전체 · 접수 · 검토중 · 완료 · 보류)로 상태별로 걸러 볼 수 있습니다.
- 그 아래 **분류**(전체 · 80 · 20 · 영업관리 · 견적서 · 기타)로도 걸러 볼 수 있습니다.
- 글이 많으면 목록 아래 **이전 / 다음** 으로 페이지를 넘깁니다.
- **답변** 칸에 `답변완료` 라고 뜨면 관리자가 답을 단 글입니다.
- 제목 뒤에 **(수정됨)** 이 붙어 있으면 글쓴이가 나중에 고친 글입니다.

**상태의 뜻**

| 상태 | 뜻 |
|---|---|
| 접수 | 글이 등록되어 확인 대기 중입니다 |
| 검토중 | 관리자가 내용을 살펴보고 있습니다 |
| 완료 | 반영되었거나 처리가 끝났습니다 |
| 보류 | 지금 당장은 어렵거나 나중에 다시 볼 건입니다 |

### 8-3. 글 열어보기 · 고치기 · 지우기

제목을 누르면 내용 전체와 **관리자 답변**이 보입니다.
답변이 아직 없으면 `아직 답변이 등록되지 않았습니다` 라고 나옵니다.

창 아래쪽에는 상황에 따라 단추가 나옵니다.

- **수정** — 내가 쓴 글은 언제든 고칠 수 있습니다. 고치면 제목 뒤에 **(수정됨)** 이 붙습니다.
- **삭제** — 내가 쓴 글이면서 **아직 관리자 답변이 달리지 않은 글**만 지울 수 있습니다.

> 답변이 달린 글을 지우면 관리자 답변까지 함께 사라지기 때문에 막아두었습니다.
> 답변이 달린 글을 꼭 지워야 하면 관리자에게 말씀해 주세요.

**관리자가 답변하기**

관리자에게는 상세 창의 **관리자 답변** 자리에 입력칸이 함께 나옵니다.

- **상태**(접수 · 검토중 · 완료 · 보류)를 고르고 답변 내용을 적은 뒤 **답변 등록** 을 누릅니다. 이미 답변이 있으면 단추가 **답변 수정** 으로 바뀝니다.
- 답변을 저장하면 목록의 **답변** 칸이 `답변완료` 로 바뀌고, 고른 상태가 함께 반영됩니다.

다른 사람이 쓴 글은 읽을 수만 있고 고치거나 지울 수 없습니다.
게시판 글은 로그인한 사람 전원이 볼 수 있으니, 개인적인 내용은 적지 말아주세요.

## 9. 수리 업무 (20)

수리품이 들어와서 나갈 때까지를 관리하는 화면입니다.
상단 메뉴 **20·80 → 20 수리등록** 으로 들어가고, 통계는 **대시보드 → 20 대시보드** 에 있습니다.

### 9-1. 입고 등록 화면 보기

![](<screenshots/20입고등록.png>)

**맨 위 숫자 카드**

| 카드 | 뜻 |
|---|---|
| 보유 수리품 | 아직 출고되지 않은 수리품 전체입니다 (일본 본사에 나가 있는 것 포함) |
| 입고 | 들어왔지만 아직 수리를 시작하지 않은 건입니다 |
| 수리중 | 지금 수리 중인 건입니다. 아래에 `국내 n · 본사 n` 으로 나뉘어 표시됩니다 |
| 출고 대기 | 수리가 끝나 나가기만 하면 되는 건입니다 |
| n월 출고완료 | 그 달에 나간 건수입니다. 좌우 화살표로 다른 달을 볼 수 있습니다 |
| 대시보드 → | 누르면 통계 화면으로 넘어갑니다 |

### 9-2. 수리품 입고 등록하기

물건이 들어오면 **입고 등록** 줄에 바로 입력합니다.

| 칸 | 설명 |
|---|---|
| **구분** | **게이지** 또는 **앰프** 중에서 고릅니다 |
| **입고일** | 오늘 날짜가 들어가 있습니다. 다르면 고칩니다 |
| **회사명** | 필수입니다. 입력하면 전에 쓴 회사명이 추천으로 뜹니다 |
| **제품 구분** | 제품 모델입니다. (예: `E-TS-4182-P6`) |
| **시리얼번호** | 제품 시리얼번호입니다 |
| **메모** | 눌러서 특이사항을 적어둘 수 있습니다. 선택입니다 |

**입고 등록** 을 누르면 목록에 **입고** 상태로 추가됩니다.

**엑셀로 한꺼번에 넣기**

여러 건을 한꺼번에 넣어야 하면 오른쪽 위 **엑셀 일괄 등록** 을 씁니다.

1. **구분**(게이지 / 앰프)과 **연도**를 고릅니다. 엑셀에 연도 없이 `8/14` 처럼 적힌 날짜를 이 연도로 읽습니다.
2. 파일을 고르면 아래에 **미리보기 표**가 나옵니다. 월-주차 · 입고일 · 회사명 · 제품 구분 · 시리얼번호 · 출고일이 어떻게 읽혔는지 확인할 수 있습니다.
3. 날짜를 못 읽었거나 회사명이 비어 있는 줄은 빨간 글씨로 표시되고 **등록되지 않습니다.**
4. 아래 **n건 가져오기** 를 누르면 등록됩니다.

- 엑셀 첫 시트에 **입고일 · 회사명 · 제품 구분 · 시리얼번호 · 출고일** 열이 있어야 합니다.
- 출고일이 채워져 있는 줄은 바로 **출고완료** 상태로 들어갑니다.

### 9-3. 수리 진행 단계

목록의 **상태 변경** 칸에 있는 단추를 누르면 다음 단계로 넘어갑니다.
지금 누를 수 있는 단추만 보이므로 순서를 외울 필요는 없습니다.

```
입고  ──[수리 시작]──▶  수리중  ──[수리 완료]──▶  출고대기  ──[출고]──▶  출고완료
```

**일본 본사로 보내는 경우**

국내에서 못 고치는 건은 일본 본사로 보냅니다.
그 줄의 오른쪽 **수정**(연필 모양)을 눌러 **특이사항** 을 **본사수리** 로 바꾸고
**본사 발송일** 을 적습니다.

- 그러면 목록에 **일본 본사** 배지가 붙고, 진행 단추가 **한국 도착** 으로 바뀝니다.
- 물건이 돌아오면 **한국 도착** 을 누르고 복귀 날짜를 넣습니다. 상태가 **출고대기** 가 되어
  이후에는 평소대로 **출고** 를 누르면 됩니다.

**그 밖의 특이사항**

| 특이사항 | 뜻 |
|---|---|
| 본사수리 | 일본 본사로 보내 수리하는 건 |
| 수리불가 | 고칠 수 없는 건 |
| 수리진행안함 | 고객이 수리를 원하지 않아 진행하지 않는 건 |

수리불가 · 수리진행안함으로 두면 진행 단추가 더 이상 나오지 않습니다.

### 9-4. 목록에서 찾기와 고치기

- 가운데 **게이지 / 전체 / 앰프** 로 종류를 나눠 볼 수 있습니다.
- 오른쪽 **전체 / 입고 / 출고완료** 로 상태를 고릅니다.
- 그 옆 **돋보기 아이콘**을 누르면 검색칸이 열립니다. **회사명 · 제품 구분 · 시리얼번호**로 찾을 수 있습니다.
- 검색칸 옆에서 정렬 기준을 **입고 / 출고** 중에서 고를 수 있습니다.
- 목록이 길면 아래 **이전 / 다음** 으로 페이지를 넘깁니다.
- 화면 위쪽에는 **수리 진행 중** 과 **출고 대기** 가 항상 따로 모여 보입니다.
  지금 챙겨야 할 건이 아래로 밀리지 않게 하기 위해서입니다.
- 📋 표시가 있는 줄은 메모가 있는 건입니다. 눌러보면 내용이 뜹니다.
- 잘못 입력했거나 내용을 바꿔야 하면 줄 오른쪽 **수정**(연필 모양)을 누릅니다.
- 잘못 등록한 건은 수정 창 왼쪽 아래 **삭제** 로 지웁니다.
- 상태를 앞 단계로 되돌리면 `상태를 되돌리면 이후 단계의 기록이 지워집니다` 라는 확인 창이 먼저 나옵니다.

### 9-5. 수리 건으로 견적서 만들기

수리비를 청구해야 하면, 그 줄의 **수정** 창을 열고 아래쪽 **+ 견적서 작성** 을 누릅니다.

- 견적서 화면으로 넘어가면서 회사명 같은 정보가 미리 채워집니다.
- 견적을 확정하면 그 수리 건과 자동으로 연결됩니다.
- 연결이 되면 목록 **견적** 칸에 금액이 뜨고, 눌러서 견적서 PDF를 바로 볼 수 있습니다.

견적이 연결되면 수정 창 아래에 그 견적의 **청구 금액**이 표시되고, 옆에서 **견적서 열기** 와 **연결 해제** 를 할 수 있습니다.
이미 연결된 상태에서 **+ 견적서 작성** 을 다시 누르면 새 견적으로 바꿀지 먼저 물어봅니다.

> 저장하지 않은 내용이 있으면 "저장 후 이동" 을 물어봅니다.
> 국내에서 수리한 건은 발주 과정 없이 **수리중 → 세금계산서 요청** 으로 바로 넘어갑니다 (4-2절 참고).

### 9-6. 수리 현황 대시보드

메뉴 **20 → 수리 현황 대시보드**, 또는 입고 등록 화면의 **대시보드 →** 로 들어갑니다.

![](<screenshots/20대시보드.png>)

숫자를 보는 화면이라 입력할 것은 없습니다. 볼 수 있는 것은 다음과 같습니다.

- **현재 입고 구성** — 지금 보유 중인 수리품이 어느 단계에 몇 개인지 원 그래프로 보여줍니다.
- **적체 Top 5** — 아직 안 나간 것 중 가장 오래된 5건입니다. 경과일이 빨간 글씨로 나옵니다.
- **숫자 카드** — 보유 수리품 · 수리중 · 출고 대기 · 이번 달 출고완료, 그리고 소요일 지표들입니다.
  전체 / 게이지 / 앰프별 **입출고 평균 소요일**, **본사 평균 소요일**(복귀 완료 건), 전체 / 게이지 / 앰프별 **작업 평균 소요일**, **이번 달 본사 발송**(복귀 건수 포함).
- **월별 입출고**(전체 · 게이지 · 앰프) · **입출고 소요기간 분포** · **최근 8주 입고** — 흐름을 보는 막대 그래프입니다.
- **월별 매출 · 월별 잔량** — 출고일을 기준으로 한 매출과, 달마다 남아 있던 수량입니다.
- **재입고 목록** — 같은 제품이 다시 들어온 이력입니다. 접수 횟수와 최근 접수일이 나옵니다.
- **주요 고객 Top 5 · 모델별 Top 5** — 건수가 많은 순입니다.

위쪽 **기간**(전체 / 연도)으로 범위를 바꿀 수 있고, **← 목록으로** 로 돌아갑니다.

## 10. 영업관리 담당자용

영업관리 권한이 있는 분에게만 상단 메뉴에 **영업관리** 가 보입니다.
그 안의 **발주관리** 화면에서 영업 담당자들이 올린 발주 건을 이어받아 처리합니다.

(같은 메뉴 안의 **재고관리** 는 10-5절에서 이어서 설명합니다.)

### 10-1. 발주관리 화면 보기

![](<screenshots/발주관리 페이지 , 영업관리용.png>)

**맨 위 숫자 카드 4개**

지금 각 단계에 몇 건이 있는지 한눈에 보여줍니다.

| 카드 | 뜻 |
|---|---|
| 주문 대기 | 발주서가 올라왔고 아직 본사 주문을 안 넣은 건 (**내가 처리할 일**) |
| 주문 완료 | 주문을 넣고 출하예정일까지 잡힌 건 |
| 세금계산서 요청 | 영업 담당자가 계산서 발행을 요청한 건 (**내가 처리할 일**) |
| 매출 완료 | 계산서까지 끝난 건 |

**목록에서 보이는 것**

| 칸 | 설명 |
|---|---|
| 견적서(견적번호) | 누르면 견적을 볼 수 있고, 옆 **PDF** 로 견적서를 엽니다 |
| 고객사 · 담당자 | 어느 업체 건이고 누가 낸 견적인지 보여줍니다 |
| 배송 | **직납** 또는 **택배발송** 입니다. 택배발송이고 주소가 있으면 눌러서 배송 정보를 펼쳐 볼 수 있고, **주소 복사** 로 주소를 복사할 수 있습니다 |
| 공급가액 · 발주일 | 금액과 발주서를 등록한 날짜입니다 |
| 출하예정 · 메모 | 주문완료 처리를 하면서 넣은 값입니다. 아직 없으면 `-` 입니다 |
| 상태 | 지금 단계입니다. 주문완료·매출완료 건에는 **처리한 담당자 이름**이, 세금계산서 요청 건에는 **요청일**이 함께 표시됩니다 |
| 발주서 | **PDF** 를 누르면 영업 담당자가 올린 발주서를 볼 수 있습니다 |
| 처리 | 지금 할 수 있는 작업 단추가 나옵니다 |

검색칸에 **견적번호 / 고객사** 를 넣거나, 옆의 상태 단추로 걸러 볼 수 있습니다.

### 10-2. 주문완료 처리하기

본사에 주문을 넣고 나서 하는 작업입니다. **발주(주문 대기)** 상태의 건에만 단추가 보입니다.

**주문완료 처리** 를 누르면 창이 열립니다.

![](<screenshots/주문완료처리, 영업관리용.png>)

- **출하 예정일** — 물건이 나갈 예정일을 고릅니다.
- **기타사항** — 납품 조건이나 특이사항을 적습니다. (예: `기상조건에 따라 지연 가능성 있음`)

**주문완료 확정** 을 누르면 상태가 **주문완료** 로 바뀌고, 견적을 낸 담당자에게 알림이 갑니다.
여기서 넣은 출하예정일과 메모는 그 담당자의 **내 견적** 목록에도 그대로 보입니다.

> 출하 예정일이나 메모가 나중에 바뀌면, 그 줄 오른쪽 끝 **⋮** 를 눌러
> **일정/메모 수정** 창에서 언제든 고칠 수 있습니다.

### 10-3. 세금계산서 발행 완료 처리하기

영업 담당자가 계산서를 요청하면 상태가 **세금계산서 요청** 이 되고 **발행완료 처리** 단추가 나옵니다.

단추를 누르면 요청 내용(요청일)이 표시된 확인 창이 열립니다.
**발행완료 확정** 을 누르면 상태가 **매출완료** 로 바뀌고, 견적을 낸 담당자에게 알림이 갑니다.

이 단계까지 끝나면 그 금액이 담당자의 매출 실적으로 잡힙니다.

### 10-4. 엑셀 내보내기 ⚠️

발주관리 화면에서도 왼쪽 체크박스로 건을 고른 뒤 **엑셀 내보내기 (n)** 를 누를 수 있습니다.
내용과 주의사항은 4-8절과 같습니다.

> **이 파일에는 원가와 이익률이 들어 있습니다. 외부로 절대 내보내지 마세요.**

### 10-5. 재고관리

상단 메뉴 **영업관리 → 재고관리** 로 들어갑니다. 부품 재고를 관리하는 화면입니다.

위쪽에 숫자 카드가 있습니다.

| 카드 | 뜻 |
|---|---|
| 총 품목 수 | 등록된 부품 종류 수입니다 |
| 총 재고 수량 | 지금 남아 있는 전체 수량입니다 |
| 승인 대기 | 아직 처리하지 않은 출고 요청 건수입니다. 있으면 **승인 필요** 라고 표시됩니다 |

아래는 네 개의 탭으로 나뉩니다.

| 탭 | 하는 일 |
|---|---|
| **재고 목록** | 재고번호 · 부품코드 · 품명 · PO번호 · 제번 · 수량 · 보관장소 · 매입일자를 봅니다. 여기서 **출고 요청**을 넣습니다 |
| **출고·재입고 이력** | 언제 무엇이 얼마나 나가고 들어왔는지 기록입니다. 신청자와 승인자가 함께 남습니다 |
| **요청 이력** | 내가 넣은 출고 요청과 그 처리 결과입니다 (관리자에게는 요청자 이름도 함께 나옵니다) |
| **승인 관리** | 다른 사람이 넣은 출고 요청을 **승인**하거나 **반려**합니다 (관리 권한이 있을 때만 보입니다) |

**찾기**

- 검색칸에 **부품코드 또는 품명**을 넣어 찾습니다.
- 옆에서 보관장소를 **전체 / 1층 / 2층** 으로 걸러 봅니다.

**출고 요청하기**

재고 목록에서 품목의 **출고 요청** 을 누릅니다.

| 칸 | 설명 |
|---|---|
| **요청 수량** | 개수입니다 |
| **출고 업체** | 필수입니다. 어디로 나가는지 적습니다 |
| **출고 사유** | 필수입니다. 사유 또는 사용처를 적습니다 |
| **비고** | 추가로 전달할 내용이 있으면 적습니다. 선택입니다 |

보내면 승인 권한이 있는 분에게 **출고 요청 승인 필요** 알림이 갑니다.

**승인 · 반려하기**

**승인 관리** 탭에 대기 중인 요청이 모입니다.

- **승인** 하면 재고 수량이 그만큼 줄고 출고 이력에 남습니다.
- **반려** 할 때는 사유를 적습니다. 재고는 줄지 않습니다.

**재입고**

출고했던 것이 되돌아오면 **출고·재입고 이력** 에서 그 줄의 **재입고** 를 눌러 처리합니다.
재입고 수량과 사유를 넣고 확인하면 수량이 다시 늘어납니다.

> 여기서도 **내가 넣은 요청을 내가 승인하면 나에게는 알림이 오지 않습니다** (11-1절).

### 10-6. 재고 엑셀 일괄 처리

여러 건을 한꺼번에 넣고 뺄 때 씁니다. 재고 화면의 **엑셀 일괄 처리** 를 누릅니다.

1. **처리 유형** 을 **출고** 또는 **입고** 중에서 고릅니다.
2. 엑셀 파일을 끌어다 놓거나 눌러서 고릅니다.
3. 아래 **미리보기**로 어떻게 읽혔는지 확인합니다 (최대 10행까지 보여줍니다).
4. **n행 출고 처리 / n행 입고 처리** 를 누르면 실행됩니다.

**엑셀에 있어야 하는 열**

| 유형 | 열 |
|---|---|
| 출고 | 재고번호 · **부품코드** · 품명 · **출고수량** · 출고업체 · 사유 · 부서명 |
| 입고 | 재고번호 · **부품코드** · 품명 · PO No. · 제번 · **수량** · 보관장소 · 매입일자 · 부서명 |

굵게 표시된 **부품코드**와 **수량**은 반드시 있어야 합니다.

처리가 끝나면 **성공 n건 / 실패 n건**이 표시되고, 실패한 줄은 이유와 함께 나옵니다.

| 실패 이유 | 뜻 |
|---|---|
| 부품코드 없음 | 그 줄에 부품코드가 비어 있습니다 |
| 미등록 부품코드 | 재고에 없는 부품코드입니다 |
| 수량 오류 | 수량이 0 이하이거나 숫자가 아닙니다 |

> 출고는 **승인 절차 없이 바로 재고에서 빠집니다.** 파일을 올리기 전에 미리보기로 꼭 확인해 주세요.

## 11. 알아두면 좋은 점

### 11-1. 내가 처리한 건은 나에게 알림이 오지 않습니다 ⚠️

가장 많이 오해하시는 부분입니다.

**알림은 "다음 사람"에게 갑니다. 방금 처리한 본인에게는 오지 않습니다.**

예를 들어 이렇습니다.

| 내가 한 일 | 알림 받는 사람 | 나에게 알림이 오는가 |
|---|---|---|
| 발주서 등록 | 영업관리 담당자들 | **오지 않습니다** |
| 주문완료 처리 (영업관리) | 견적을 낸 담당자 | **오지 않습니다** |
| 계산서 요청 | 영업관리 담당자들 | **오지 않습니다** |
| 발행완료 처리 (영업관리) | 견적을 낸 담당자 | **오지 않습니다** |

그래서 **"발주서를 등록했는데 알림이 안 와요"** 는 고장이 아니라 정상입니다.
내가 한 일을 나에게 다시 알려줄 필요가 없기 때문에 일부러 그렇게 만들어 두었습니다.

내가 처리한 내용이 제대로 반영됐는지 확인하려면 **알림이 아니라 목록의 상태 배지**를 보세요.
발주서를 등록했으면 상태가 **발주(주문 대기)** 로 바뀌어 있어야 합니다.

> 참고로, 견적을 낸 사람과 처리한 사람이 **같은 사람**이면
> 그 건에 대해서는 어느 단계에서도 알림이 오지 않습니다.

**알림 보는 곳**

- 화면 오른쪽 위 **종 모양** 아이콘. 안 읽은 개수가 빨간 숫자로 붙습니다.
- 개인 대시보드의 **알림** 카드에는 최근 다섯 건만 나옵니다. 전체는 종 모양 아이콘에서 봅니다.
- 알림을 누르면 읽음 처리되고, 관련 화면으로 바로 넘어갑니다.

### 11-2. 금액과 원가를 다룰 때 주의할 점 ⚠️

이 시스템에는 **고객에게 보여줄 숫자**와 **회사 내부에서만 보는 숫자**가 섞여 있습니다.
어느 쪽인지 늘 구분해 주세요.

**고객에게 나가도 되는 것**

- 견적서 **PDF** — 품번·품명·수량·단가·공급가액·부가세·합계만 들어 있습니다.

**절대 나가면 안 되는 것**

| 대상 | 왜 |
|---|---|
| **엑셀 내보내기 파일 (.xlsx)** | 본사 구입가(원가), 품목별 이익·이익률이 그대로 들어 있습니다 |
| **수익 분석 화면** | 견적서 작성 화면 왼쪽의 원가·이익률입니다 |
| **부대비용 내역** | 서비스비의 원가 내역입니다. 견적서 PDF에는 나오지 않습니다 |
| **목록의 순이익 칸** | 내 견적 목록·발주관리 목록에 나오는 이익 금액과 이익률입니다 |

**국내조달품은 특별히 조심**

국내조달품은 고객 견적서에서 **단가·공급가액·부가세가 `-` 로** 나갑니다.
금액이 빠진 게 아니라, 우리가 부담하는 원가라서 일부러 감춘 것입니다.
고객이 "여기 금액이 왜 비어 있냐" 고 물으면 서비스 안에 포함된 항목이라고 안내하시면 됩니다.
**절대 그 원가 금액을 알려주지 마세요.**

**그 밖에**

- 견적서 미리보기에 비스듬히 찍힌 이름은 화면 캡처 유출을 막기 위한 표시입니다.
  저장되는 PDF에는 나오지 않습니다.
- 고객과 화면을 함께 볼 일이 있으면, 견적서 작성 화면 대신 **저장된 PDF** 를 열어서 보여주세요.
- 엑셀 파일은 누가 언제 내려받았는지 기록됩니다. 다 쓰면 지워주세요.

### 11-3. 자주 묻는 질문

**Q. 견적을 안 건드렸는데 상태가 「실패」로 바뀌었습니다.**
견적일로부터 30일이 지나도록 **견적중**이던 건은 자동으로 실패 처리됩니다. 실패 사유에 `유효기간 만료 (30일)` 이 남습니다 (4-6절).
이 건은 되돌릴 수 없으니 아직 살아 있는 건이라면 **새 견적서를 작성**해 주세요.

**Q. 실패 처리한 건을 되돌릴 수 있나요?**
사람이 손으로 실패시킨 건은 **⋮ → 견적중** 으로 되돌릴 수 있습니다 (4-7절). 자동으로 실패된 건은 되돌리기 선택지가 나오지 않습니다.

**Q. 견적서 사명에 업체명을 적었는데 저장이 안 됩니다.**
직접 입력한 글자로는 저장되지 않습니다. **검색 결과 목록에서 골라야** 합니다.
목록에 없으면 고객사 현황에서 업체를 먼저 등록해 주세요 (2-5절, 3-2절).

**Q. 이 부품이 어느 업체에 나갔는지 찾고 싶습니다.**
고객사 현황 검색창 안의 **업체 / 부품** 을 **부품** 으로 바꾸고 품번을 두 글자 이상 넣으시면 됩니다 (2-3절).

**Q. 견적서를 잘못 만들었습니다. 지울 수 있나요?**
직접 지울 수는 없습니다. 내 견적 목록에서 **⋮ → 삭제** 를 골라 사유를 적고 **삭제 요청** 을 보내세요.
관리자가 승인하면 처리됩니다. 확정한 견적은 실적에 잡히기 때문에 이렇게 되어 있습니다.

**Q. 수주에 실패했습니다. 그냥 두면 되나요?**
**⋮ → 실패** 를 골라 사유를 적고 확정해 주세요. 그래야 목록이 깔끔해지고 실적 집계도 정확해집니다.

**Q. 상단 메뉴에 어떤 메뉴가 안 보입니다.**
메뉴는 **팀별 권한**에 따라 달라집니다 (1-2절). 필요한 메뉴가 안 보이면 관리자에게 말씀해 주세요.
권한을 받은 뒤에는 **화면을 새로고침해야** 메뉴에 반영됩니다.

**Q. 발주서 등록 단추가 안 보입니다.**
**견적중** 상태일 때만 나옵니다. 이미 등록했거나(발주(주문 대기)), 국내 수리 건이면 나오지 않습니다.
국내 수리 건은 발주 없이 바로 **계산서 요청** 으로 갑니다.

**Q. 계산서 요청 단추가 안 보입니다.**
**주문완료** 상태여야 나옵니다. 아직 **발주(주문 대기)** 라면 영업관리 담당자가 주문완료 처리를 해야 합니다.

**Q. 택배발송인데 받는 담당자 목록이 비어 있습니다.**
그 고객사에 담당자가 등록되어 있지 않은 것입니다. 고객사 화면에서 담당자를 먼저 등록해 주세요 (2-7절).

**Q. 가격표에 없는 제품은 어떻게 넣나요?**
**수동입력** 으로 넣습니다 (3-3절). 원가를 엔화로 직접 적으면 나머지는 자동으로 계산됩니다.

**Q. 납기를 적었는데 왜 자동으로 바뀌나요?**
납기를 비워두면 품목을 고를 때 가격표의 납기가 자동으로 채워집니다.
직접 적어두셨다면 그대로 유지됩니다.

**Q. 견적 번호는 어떻게 붙나요?**
자동으로 만들어집니다. 확정하고 나면 뒤 알파벳이 하나 올라가서 다음 견적서를 바로 이어서 쓸 수 있습니다.

**Q. 현장에서 못 끝낸 건은 어떻게 남기나요?**
그 장비의 서비스 기록에 마우스를 올려 **홀딩** 버튼을 눌러 걸어두시면 됩니다 (2-12절).
걸어둔 건은 80 대시보드와 홀딩 현황(6장)에 모여 경과 일수와 함께 보입니다.

**Q. 목록에서 예전 견적이 안 보입니다.**
기간 선택이 **유효 견적**(작성일 + 1개월 이내)으로 되어 있기 때문입니다.
월간 · 분기 · 반기 · 연간으로 바꿔서 보세요.

**Q. 화면이 이상하거나 불편한 점이 있습니다.**
**건의사항** 게시판에 남겨주세요 (8장). 어느 화면에서 무엇을 하다가 그랬는지 함께 적어주시면 좋습니다.

## 12. 관리자용 기능

> **이 장은 관리자 권한이 있는 분만 해당됩니다.**
> 아래 메뉴들은 권한이 없으면 상단 메뉴에 아예 보이지 않습니다.
> 일반 사용자는 이 장을 읽지 않으셔도 됩니다.

### 12-1. 유지보수 화면 보기

상단 메뉴 **관리자 → 유지보수** 로 들어갑니다. 관리 기능이 카드 형태로 놓여 있고,
각 카드의 **관리하기** 를 누르면 해당 창이 열립니다.

![](<screenshots/유지보수 전체.png>)

| 카드 | 하는 일 |
|---|---|
| 🎯 **목표 금액 관리** | 연간 목표 금액을 개인별 / 팀별로 정하고 수정합니다 (12-2절) |
| 🗑️ **견적서 삭제** | 잘못 저장된 견적서를 찾아 삭제합니다 (12-3절) |
| 👥 **직원 관리** | 직원 등록, 정보 수정, 권한 변경, 계정 삭제를 합니다 (12-4절) |
| 🏷️ **팀 관리** | 팀을 추가·삭제하고 **팀별 권한**을 정합니다 (12-5절) |
| 🧾 **부대비용 단가** | 견적서 서비스비의 부대비용 표준 항목과 단가를 관리합니다 (12-6절) |
| 📊 **가격표 업로드** | 준비 중입니다. 단추가 회색으로 눌리지 않습니다 |
| 📋 **다운로드 로그** | 견적서 PDF를 누가 언제 내려받았는지 조회합니다 (12-7절) |

> **직원 관리 · 팀 관리 · 부대비용 단가** 는 관리자(최고관리자)만 쓸 수 있습니다. 권한이 없으면 단추가 회색으로 눌리지 않습니다.

### 12-2. 목표 금액 관리

![](<screenshots/목표금액.png>)

연도를 고르고, 직원마다 **수주 목표**와 **매출 목표** 금액을 넣습니다.

- 맨 위에 **계측부 전체 목표**(수주 · 매출)가, 팀마다 **소계**가 표시됩니다.
- 줄 오른쪽 **수정**(아직 없으면 **설정**)을 눌러 금액을 넣고 저장합니다.
- 매출 목표를 넣으면 옆에 **월 환산 금액**이 함께 표시됩니다. 월·분기 목표는 연간 목표에서 자동으로 계산됩니다.
- 아직 넣지 않았으면 **미설정** 으로 표시됩니다.
- 수주·매출 목표는 각각 선택 입력이며, **둘 다 비운 채 저장하면 그 목표가 삭제됩니다.**

여기서 넣은 값이 각자의 **내 견적** 화면 위쪽 달성률(4-1절)과 **실적 현황**(12-8절)의 달성률 기준이 됩니다.

### 12-3. 견적서 삭제 (신중히 ⚠️)

견적번호로 찾아서 지웁니다. 사용자가 **삭제 요청**(4-2절)을 보낸 건도 여기서 처리합니다.

- 검색칸에 견적번호를 넣고 **검색** 을 누르면 견적번호 · 날짜 · 담당자 · 고객사 · 금액 · 상태가 표로 나옵니다.
- 줄 오른쪽 **삭제** 를 누르면 확인 창이 열립니다.

> **한 번 지우면 되돌릴 수 없습니다.** 확인 창의 견적번호를 꼭 다시 보고 누르세요.
> 확정된 견적은 실적에 잡혀 있으므로, 지우면 그 사람의 실적 숫자도 함께 바뀝니다.

### 12-4. 직원 관리

![](<screenshots/직원삭제.png>)

직원 목록에 **이름 · 직책 · 팀 · 이메일 · 이니셜 · 권한**이 나옵니다.

**직원 등록** — 오른쪽 위 **+ 직원 등록** 을 누릅니다.

| 칸 | 설명 |
|---|---|
| **이름** | 필수입니다 |
| **직책** | 필수입니다. 사장 · 총괄 · 수석 · 책임 · 선임 · 사원 중에서 고르거나 직접 적습니다 |
| **팀** | 필수입니다. 팀 관리(12-5절)에서 만든 팀 중에서 고릅니다. **이 팀이 그 사람의 화면 권한을 정합니다** |
| **사무실** | 동탄 · 울산 · 구미 중에서 고릅니다. 활동 현황의 **동선 지도**(7-3절)에서 출발·복귀 지점으로 쓰입니다 |
| **이메일** | 필수입니다. **로그인 아이디**가 됩니다 |
| **초기 비밀번호** | 필수입니다. 본인이 로그인한 뒤 바꾸도록 안내해 주세요 (1-4절) |
| **이니셜** | 필수입니다. **견적번호에 쓰입니다** (예: `No.HGD20260511-A`) |

**정보 수정** — 줄 오른쪽 **수정** 을 누릅니다. 이름 · 직책 · 팀 · 사무실 · 이메일과 **권한**을 바꿉니다.

| 권한 | 할 수 있는 일 |
|---|---|
| **관리자** | 팀과 상관없이 모든 화면을 보고, 관리자 메뉴를 씁니다 |
| (체크 안 함) | **팀원**입니다. 화면 권한은 소속 팀의 설정을 따릅니다 (12-5절) |

**직원 삭제(퇴사 처리)** — 줄 오른쪽 **삭제** 를 누르고 **삭제일**을 고릅니다.

- 로그인이 차단되고 직원 목록에서 사라집니다.
- **과거 견적·활동 기록의 작성자 이름은 그대로 남습니다.** 실적과 이력이 사라지지 않습니다.
- 되돌릴 수 없으며, 다시 근무하게 되면 **직원 등록으로 새로 만들어야** 합니다.

### 12-5. 팀 관리와 권한

**화면 권한은 팀 단위로 정합니다.** 이 화면이 그 설정을 하는 곳입니다.

![](<screenshots/유지보수 팀 추가 및 권한.png>)

- **+ 새 팀 추가** 를 누르면 팀 이름을 넣는 칸이 펼쳐집니다. 이름을 넣고 **추가** 를 누르면 팀이 만들어집니다.
- 표의 한 줄이 한 팀이고, 오른쪽 여섯 칸이 권한입니다.

| 권한 | 열리는 화면 |
|---|---|
| 고객사 | 고객사 현황 · 업체 상세 · 20 수리등록 |
| 대시보드 | 20 대시보드 · 80 대시보드 · 활동 현황 |
| 견적서 | 견적서 작성 (고객사 화면의 부품 검색도 이 권한을 봅니다) |
| 영업 현황 | 영업기회 판 |
| 영업관리 | 발주관리 · 재고관리 |
| 관리자 | 실적 현황 · 유지보수 |

- **체크박스를 누르면 그 자리에서 바로 저장됩니다.** 따로 저장 단추는 없습니다.
- 열 제목에 마우스를 올리면 그 권한이 어떤 화면을 여는지 설명이 뜹니다.
- 오른쪽 **삭제** 로 팀을 지웁니다. **재직 중인 직원이 배정된 팀은 삭제할 수 없습니다.**
- 권한 변경은 곧바로 반영되지만, **그 사람의 상단 메뉴는 화면을 새로고침해야** 바뀝니다.

> 팀을 새로 만들면 권한은 전부 꺼진 상태입니다. 필요한 것만 켜주세요.
> 관리자 권한을 가진 직원은 팀 설정과 무관하게 모든 화면을 봅니다 (12-4절).

### 12-6. 부대비용 단가

![](<screenshots/부대비용 추가 변경.png>)

견적서에서 서비스비의 부대비용을 넣을 때 불러 쓰는 **표준 항목과 단가**입니다 (3-3절).

- 위쪽 **새 항목 추가** 에 항목명과 단가(선택)를 넣고 **추가** 를 누릅니다.
- 목록의 **항목명이나 단가를 누르면 그 자리에서 수정**할 수 있고, 오른쪽 **삭제** 로 지웁니다.
- 단가를 비워두면 **미정** 으로 표시됩니다. 금액이 정해지지 않은 항목은 이렇게 두면 됩니다.
- 여기서 바꾼 값은 이후 새로 작성하는 견적서에 반영됩니다. **이미 저장된 견적서의 금액은 바뀌지 않습니다.**

### 12-7. 다운로드 로그

견적서 PDF를 **누가 언제 어떤 견적을** 열어보고 내려받았는지 남는 기록입니다.

- 표에 일시 · 담당자 · 견적번호 · 고객사 · 구분(**열람** / **다운로드**)이 나옵니다.
- 원가가 들어간 파일이 외부로 나갔는지 확인할 때 이 화면을 보시면 됩니다 (11-2절).

### 12-8. 실적 현황

상단 메뉴 **관리자 → 실적 현황** 입니다. 회사 전체의 영업 실적을 보는 화면입니다.

**기간 고르기**

- 왼쪽에서 **회계연도(FY)** 를 고르고, 옆에서 **연간 · H1 · H2 · 분기 · 월별** 을 고릅니다.
  분기·월별을 고르면 옆에 분기(Q1~Q4)나 월을 고르는 칸이 하나 더 나옵니다.
- 고른 기간 옆에 `잔여 2개월 10일` 처럼 **남은 기간**이 표시됩니다.
- 그 옆에서 **팀**을 골라 그 팀만 볼 수 있습니다.

**위쪽 숫자**

| 항목 | 뜻 |
|---|---|
| 견적 제출 | 그 기간에 낸 견적 금액과 건수 |
| 수주액 | 발주서를 받아 주문으로 이어진 금액과 건수 |
| 매출 완료액 | 세금계산서까지 끝난 금액 |
| 원가 합계 · 순이익 | 매출완료 건 기준입니다 |
| 수주 전환율 | 수주 건수 ÷ 견적 건수 |
| 전년 동기 대비 | 같은 기간 작년 대비 증감입니다 |
| 수주 달성률 · 매출 달성률 | 목표(12-2절) 대비 몇 %인지. 목표가 없으면 **미설정** 입니다 |

그 아래 **사업부 수주 달성률 · 매출 달성률**이 막대로 함께 표시됩니다.

**팀별 실적 · 개인 실적**

- 팀별, 사람별로 견적 제출 · 수주 · 매출 완료 · 순이익과 달성률이 카드로 나옵니다.
- **개인 카드를 누르면** 그 사람의 견적 목록 창이 열립니다. 목록에서 **발주서 등록 · 계산서 요청 · ⋮(삭제/실패/되돌리기) · 엑셀 내보내기**를 4장과 같은 방식으로 처리할 수 있습니다.
