**더한 것** — 밖에서 벌어진 일 일곱 종([lib/customerEvents.ts](lib/customerEvents.ts) 의 `WORK_EVENT_TYPES`):

## 6. 의뢰서 — 서버도 사업장을 요구한다

화면은 「회사 → 사업장」 2단을 이미 요구했지만 **서버는 비워 받았다.**
한 번 비워 들어온 의뢰서는 **영영 어느 사업장 것인지 모른 채** 남는다.

* 발급: `customerId === null` → **400 「사업장을 골라주세요.」**
* 수정: `body.customer_id === null` → **400 「사업장은 비울 수 없습니다.」**
  (이미 비어 있는 **과거분은 그대로 둔다** — 고치라고 막으면 고칠 길이 없어진다)
* 장비는 고른 그대로 받는다(`asId(body.device_id)`).

얕게 훑는다. `ios-overflow.js`(네 화면을 깊게)와 **따로** 둔 까닭은 「빠진 화면이 없게」가 목적이기 때문이다.

### 8-1 콘솔 — **우리 탓 0**

**배포본**(`next build` + `next start`)으로 쟀다. `next dev` 는 StrictMode 가 효과를 두 번
불러 수가 부풀고, 없는 경고가 섰다.

남은 것은 `/` 의 「카카오 지도 SDK 로드 실패」 하나인데 :3101 이 **등록된 도메인이 아니라** 그렇다
(배포본에서는 안 난다 — 지시문의 「카카오·외부 요인 제외」). 고친 것 하나:
`/sales` 가 **403** 을 찍고 있었다 — `auto-fail` 을 모두가 부르고 있었는데 **슈퍼관리자만** 부르게 했다.

### 8-2 폰 — **46조합 중 15 → 2**

390 과 **350** 두 폭, 23장 = 46조합. **빼는 규칙 없이 전 요소**의 right 를 센다.

고친 길은 하나다: **숨기지 않고 옆으로 구르게** 했다.
(2026-11-26 에 넘침을 가려 발주 표를 못 굴리게 만든 일을 되풀이하지 않는다.)

| 화면 | 무엇이 넘쳤나 | 어떻게 했나 |
|---|---|---|
| `/account` | 사진 올리는 **파일 입력칸**이 칸을 넘겼다 | 감싼 칸에 `min-width: 0`, 입력칸에 `max-width: 100%` |
| `/suggestions` | 표 여섯 칸이 `overflow: hidden` 에 **잘려** 제목을 읽을 수 없었다 | 구르는 통 + `min-width: 620` |
| `/inventory` | 탭 넷이 한 줄에 못 섰다 | 구르는 통(스크롤바는 숨긴다) |
| `/contact/semi` | 고정 칸 넷이 **520px** — 어떤 글자 크기로도 안 들어간다 | 머리·행을 **한 몸으로** 구르게(`.cs-shell` + `.cs-grid { min-width: 540px }`) |
| `/approval` | 문서 줄이 **480px** | 카드를 한 몸으로. `.ap-main` 에 **`width: 100%`** 가 있어야 한다 — `.ap-body` 의 `align-items: flex-start` 때문에 세로로 떨어진 줄이 늘어나지 않는다 |

남은 둘은 **350** 에서 `div.ems-pick` 이 **+3px**(`/activity`) · **+1px**(`/sales`) —
표 테두리 겹침의 반올림이다. **390 은 전 화면 깨끗하고**, 16px 미만 입력칸 0,
앱바 가림 0 이다. 결과: [docs/night3-phone.json](docs/night3-phone.json)

**재는 쪽 결함 하나도 고쳤다.** 조상이 `overflow: hidden` 이면 「화면이 잘렸다」고 셌는데,
그건 그 칸 안에서 **말줄임으로 자른** 자리(`tableLayout: fixed` 의 `td`)다. 가두는 조상이
화면보다 넓으면 **조상 자신이** 따로 걸리므로 자식까지 두 번 셀 까닭이 없다 —
`/repair` 의 **923건**이 여기서 왔다(화면은 멀쩡하다).
