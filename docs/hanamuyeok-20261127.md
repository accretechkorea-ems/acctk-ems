## ④ 코드에서 확인한 것 — **빈 E.U 를 받아 주는가**

지시의 물음에 답한다: **받아 준다.**

| 자리 | 어떻게 |
|---|---|
| DB | `quotes.customer_id` 는 **null 을 받는다**(not null 이 아니다) |
| 견적 저장 | 사명을 안 고르면 화면이 막는다 — 그러나 **이미 저장된 줄의 customer_id 를 비우는 길**은 막지 않는다 |
| 견적서 PDF·목록 | 고객명이 비면 빈 칸으로 그린다(터지지 않는다) |
| 실적 집계 | `customer_id` 로 묶지 않는다 — 금액·상태로 센다. **수치는 바뀌지 않는다** |

→ SQL 은 E.U 가 비면 **그대로 두고** 주석으로 표시한다(지시대로). 빈 채로 두어도 화면은
