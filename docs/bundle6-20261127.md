# 절별 자세한 것

## 1. 실적 현황

### 1-1 팀 필터

고르는 규칙을 **순수 함수 하나**로 뺐다 — `lib/salesStats.ts` 의 `scopeEngineersOf`:

```
팀을 골랐으면 — 보이는 사람 중 그 팀
「전체」면    — 집계 대상 전원 (= 전과 같은 값)
```

목표 합도 **같은 사람들**로 낸다. 팀 목표라는 칸은 따로 없다 — 그 팀 사람들의 개인
목표를 더한 것이 팀 목표이고, 「전체」면 전원 합 = 사업부 목표(전과 같다).

제목은 이미 「**80CS** 2026년 11월 실적 · 잔여 3일」이었다.

### 1-2 그래프 범위

축의 **단위는 늘 달**이고, 기간은 **보여 주는 범위**만 바꾼다(`chartMonthsOf`).
전에는 연간·분기가 네 칸(분기)이라 기간을 바꿀 때마다 축의 **뜻**이 달라졌다 —
「연간에서 보던 11월 막대」를 월별로 옮기면 같은 것을 못 찾았다.
월별에 12칸을 다 두는 까닭: 한 칸만 그리면 **많은지 적은지**를 알 수 없다.
