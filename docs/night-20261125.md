## 0. iOS 진단 페이지 — `/debug/viewport`

로그인하면 누구나 열 수 있고 **메뉴에는 없다**(`lib/menuPerms.ts` 의 `PARENT_MENU` 에
`public` 으로만 걸었다). 읽기만 하는 화면이다.

보여 주는 값: `userAgent` · `innerWidth/Height`·dpr · `document.scrollWidth` ·
`visualViewport`(width·scale·offsetLeft·pageLeft) · html/body 의 `overflow-x`·width ·
`.ems-topbar`·`.ems-main`·`.ems-sidebar` 의 자리(top·height·display·visibility·z-index·
margin-left·padding-left) · `(max-width: 768px)` 매치 여부 ·
**창 밖으로 나간 요소 10개**(selector·left·right·width·position) ·
안전 영역 `env(safe-area-inset-*)` 네 값(자리표 요소의 padding 으로 px 로 읽는다) ·
스타일시트 수와 목록 · `--color-brand` 로 본 **globals.css 적용 여부**.

「복사」 단추가 JSON 을 클립보드에 담는다. 클립보드가 막힌 기기를 위해 맨 아래에 날것
JSON 을 깔아 두고(`user-select: all`) 길게 눌러 복사할 수 있게 했다.
화면 크기·방향이 바뀌면 다시 잰다(resize·orientationchange·visualViewport).

**부탁** — 문제가 보이는 그 아이폰에서 열고 「복사」를 눌러 붙여 주시면, 어제 재현되지 않던
가로 잘림의 원인을 바로 좁힐 수 있다.
